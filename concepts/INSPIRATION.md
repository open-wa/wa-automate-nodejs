# open-wa: inspiration board

Built before any concept is designed. Agents fetch these themselves (WebFetch,
their own browser tab, or Mobbin) and close any tab they open.

## Layer 1: the functional baseline (the category's own sites)

| Site | URL | Notes |
|---|---|---|
| WAHA | https://waha.devlike.pro/ | "Get Started" hero with Docker and release badges, no code above the fold. Then three steps (start, pair, use), "Why", send/receive snippet, channels and groups snippets, Swagger, dashboard, n8n, closing CTA. Free core, $5/mo community support. Big "More" menu of 17 solution pages. Claims "No blocking". |
| whatsapp-web.js | https://wwebjs.dev/ | Library site: name, one-line tagline, Guide and Documentation buttons, three feature blurbs, licence line. No install command, no footer, claims lower ban risk. |
| Whapi.Cloud | https://whapi.cloud/ | Hosted API. Header: Features, Price, API Docs, Partners, More; Get Started Free. Hero "WhatsApp API for developers and integrations", free trial, demo video. 15 sections: features, message carousel, integrations, DX (sandbox, samples, webhooks), feature grid, three-step onboarding, stats and testimonials, white label, pricing (free sandbox, $29/mo per number), FAQ, language guides. Deep footer: free tools, integrations, resources, guides, legal. Honest notes on restrictions and re-linking. |
| Meta WhatsApp Business Platform | https://developers.facebook.com/docs/whatsapp/cloud-api | The official route: Meta business account, approved templates for conversations you start, per-message pricing. |
| Twilio WhatsApp | https://www.twilio.com/en-us/messaging/channels/whatsapp | Official-API reseller: developer and business stories split, code samples per language, pricing link. |

**Every concept matches:**
- Header with Docs, Features, Integrations, Pricing, GitHub (stars), Discord and a primary button; a phone menu with all of it.
- The run command with a Copy button in the hero, plus Quick start and Docs.
- Three-step first run (run, scan, open `/api-docs/`), real send and receive code with copy buttons.
- Capability grid, integrations, MCP/AI, free vs licensed with prices, changelog, community.
- Footer with Product, Developers, Community and Legal groups, and the "Unofficial. Not affiliated with WhatsApp or Meta." line on every page.

**Bad everywhere (where we win):**
- Heroes with no code, or code with no copy button.
- Promises about bans ("No blocking") or no word about risk at all.
- What's free and what's paid is vague; prices hidden behind sign-up.
- 15-section marketing scrolls with stats nobody can check.
- Version confusion (v4 vs v5) with no clear path.
