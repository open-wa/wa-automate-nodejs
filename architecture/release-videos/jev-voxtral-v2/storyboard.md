# Jev and Voxtral — revision 2

Reference: https://x.com/emilwidlund/status/2115213417539879300

The first cut repeated a title/subtitle/card scaffold. This revision uses a wide canvas, changes shot size, and shows a single demo appointment move through conversation, delivery, correction and selection. The reference film and its audio are not reused in the deliverable.

| Time | Shot | Visual action / inventory coverage |
| --- | --- | --- |
| 0–5 | Opening | Large outcome typography; OpenWA purpose and Voxtral versus standalone Jev identity. |
| 5–13 | Conversation | Voice-note exchange (V1) or standalone text memory (J1). |
| 13–21 | Call / decision | Call waveform stops at interruption and a new response appears (V2, V3); Jev selects, host validates, result reviewed (S1, J2). |
| 21–28 | Booking | Request details become a native card, with date, time and location (S1). |
| 28–35 | Correction | 8 pm predecessor exits, corrected 2 pm card enters, removal shown; recall does not create a duplicate card (S2). |
| 35–43 | Choices | Confirm, reminder and two drink selections, submit, acknowledgement in the current adapter (S3). |
| 43–50 | Control | Neo Chat, decision evidence, pause/takeover/resume, shared chat filter. Individual answer-failure continuation for Voxtral; optional voice/shared context for Jev (S4, H1, V4, J3). |
| 50–58 | Setup | Typed initializer, Easy API/SDK, JS/TS, browser and plugin choices, auto config discovery/lazy plugins (I1). |
| 58–70 | Closing | Stable command, guide and prerequisites; settled before 59s, held at least 11s. |

Illustrated demos remain labelled. Booking cards display details and do not reserve external slots. Film makes no package availability, performance, perfect ASR or physical-call audio-quality claim.

Direction rules: restrained emerald/white palette; one action at a time; readable end states; cursor movement only where an input occurs; no generic whooshes; musical resolution at the closing brand/CTA. The source remains scrubbable in Remotion Studio.
