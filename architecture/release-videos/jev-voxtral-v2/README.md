# Jev / Voxtral films — second cut

Two 70-second films in 1920×1080 at 30 fps. Editable Remotion TypeScript, original synthesized interaction cues and music, MP4/GIF/poster exports. Original cut is preserved in the sibling folder.

From `marketing/`: `npm ci --workspaces=false`, then `node render.js`. `npm run studio` opens the scrubbable compositions. Installed macOS Chrome and FFmpeg are required; override Chrome with `REMOTION_CHROME`.

The illustrated workflows are based on the existing feature inventory. See `storyboard.md` and `release-manifest.json` for scope and qualifications. The reference thread influenced pacing, framing and cue design; no reference video or sound is included.
