# OpenWA + Lightpanda launch artwork

A 32-second product film with a titanium / emerald engine reveal, animated
memory comparison, timing count-up, metric recap, and a final onboarding card. Created in
Remotion 4.0.534 at 1080 × 1350, 30 fps. The MP4 includes original, procedurally
synthesized ambient sound design. The GIF is silent and loops.

The opening explains OpenWA: it turns WhatsApp into an API for apps, bots and
integrations. The closing card uses the repository's `open-wa` wordmark and
canonical `https://openwa.dev` URL. It shows the exact command below, followed
by QR pairing through WhatsApp's Linked devices and the local `/dashboard/`.
The complete card settles by 22 seconds and stays visible through 32 seconds.
The poster uses this same onboarding card.

```sh
npx @open-wa/wa-automate --lightpanda
```

This is the CTA for the upcoming minor release's experimental Lightpanda path.
Node.js 22.21.1 or newer is required; the driver supports macOS/Linux, with WSL2
required on Windows. The closing card explicitly says to run it after release.
The package bin is defined in `packages/wa-automate/package.json`; the parser's
`--lightpanda` handling and printed dashboard URL are in `src/cli-runtime.ts`.
Brand text comes from `apps/docs/src/lib/layout.shared.tsx` and the URL from
`apps/docs/src/lib/site.ts`, relative to the repository root.

## Claims and provenance

All figures come from `../results.json`, with interpretation in `../report.md`.
`src/metrics.ts` reads the actual single-session medians directly from that
evidence. No benchmark was rerun to produce this artwork.

| Displayed claim | Basis |
| --- | --- |
| 95.6% lower peak browser RSS | Chrome: 985.09375 MiB; Lightpanda: 43.65625 MiB. `(1 - 43.65625 / 985.09375) × 100`, rounded to one decimal. |
| 10× faster launch to first result | Chrome: 1252.166375 ms; Lightpanda: 124.836542 ms. Ratio 10.0304, rounded to the nearest whole multiplier. |
| 4.3× faster over 20 repeat loads | Chrome: 787.424625 ms; Lightpanda: 183.364167 ms. Ratio 4.2944, rounded to one decimal. |

The controlled workload fetches 1,000 records from a local server, inserts
1,000 DOM nodes, and checks the extraction. Every sample uses one fresh
browser process, then runs 20 warm navigations. These are the medians of five
alternating-order runs on an Apple M1 Pro, 8 CPU cores, 16 GiB RAM, macOS 26.6.2.
Engines: Lightpanda 1.0.0 and Chrome 154.0.8037.58.

RSS sums each benchmark-owned browser process tree. It excludes the Node
controller and sampler, and shared physical pages can be counted more than
once. This is browser RSS, not private memory or a guaranteed server-capacity
improvement. First result means the first checked DOM extraction from process
launch; it is not WhatsApp login time.

The artwork retains a persistent readable benchmark footer, marks the driver
as an experimental preview, and ends with “Authenticated WhatsApp performance
not measured.” Reload recovery is explicitly still in progress. These measurements describe the successful controlled DOM
workload. The WhatsApp QR experiment needed a separately prepared binary and
experimental worker / crypto bridges; it does not establish these gains for
authenticated OpenWA sessions, long-running operation, or reliable session restoration.
Earlier custom native Debug runs reached READY and loaded chats/contacts, but
later reloads failed with session takeover and initialization errors. The stock
download remains unchanged. No WhatsApp sync-speed or Chrome-parity claim is
made by this film.

## Edit and render

The package is isolated from the repository dependency tree. Run these
commands from this `marketing/` directory:

```sh
npm ci --workspaces=false
node sound-design.mjs
npm run studio
npm run render -- --browser-executable='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome'
npm run poster -- --browser-executable='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome'
ffmpeg -i exports/openwa-lightpanda-launch.mp4 -vf 'fps=15,scale=648:810:flags=lanczos,split[s0][s1];[s0]palettegen=max_colors=160:stats_mode=diff[p];[s1][p]paletteuse=dither=bayer:bayer_scale=4:diff_mode=rectangle' -loop 0 exports/openwa-lightpanda-launch.gif
```

The browser-executable option is optional on machines where Remotion manages
its own browser. All motion is driven by Remotion's frame clock. Source is in
`src/launch.tsx`; `LightpandaLaunch` is the film and `LightpandaPoster` is the still.
The original WAV is regenerated by `sound-design.mjs`.

## Assets

Typography uses the Inter variable font from the official Google Fonts
repository, distributed under the SIL Open Font License in `public/Inter-OFL.txt`.
The chip, lighting, background and charts are original vector / CSS artwork.
There are no sampled sounds, stock images, Apple marks, or third-party product
renders. The visual treatment is an independent product-launch style.

Rendered output was inspected at the intro, settled memory comparison, timing
comparison and final onboarding scene. The final MP4 contains 1080 × 1350 H.264 video at
30 fps and 48 kHz AAC audio. No tests, typechecks, lint checks, application builds,
CI workflows or additional performance measurements were run for this artwork.
