⬆️ The experimental Lightpanda driver now uses Lightpanda 1.0.5. A WhatsApp session links, restarts from its saved login and sends text and images without a custom browser build, and the same `.data.json` login moves between Chrome and Lightpanda. Lightpanda still uses more memory and CPU than Chrome on a long-running session, and stickers and audio sends don't work on it.
