# Link-code login

If your WhatsApp account supports pairing codes, you can request an eight-digit link code instead of scanning a QR code.

## Configure Easy API

Pass the `--link-code` CLI flag with the phone number:

```bash
npx @open-wa/wa-automate@alpha --link-code "447123456789"
```

You can also specify the property in `wa.config.mjs`:

```js
export default {
  linkCode: '447123456789',
};
```

## Phone number format

Specify the full phone number including the country code. Do not include a plus sign (`+`), spaces, brackets, or hyphens.

For example, use `447123456789` instead of `+44 7123 456789`.

## Retrieve the link code

The pairing code is printed in the terminal logs when the runtime initializes.

## Complete authentication on your mobile device

On the mobile phone that owns the WhatsApp account:

1. Open WhatsApp.
2. Tap **Settings** (iOS) or the three-dot menu (Android).
3. Select **Linked Devices**.
4. Tap **Link a Device**.
5. Select **Link with phone number instead**.
6. Enter the eight-digit code displayed by open-wa in your terminal.
7. Confirm the pairing prompt on your device.

## Expiration and error handling

Pairing codes expire after a short interval. If the code expires or is entered incorrectly, WhatsApp rejects the pairing attempt and the session does not connect.

To generate a new pairing code, restart the CLI process and enter the updated code on your device.

## QR code fallback

The runtime can still display a QR code in the terminal alongside the link code. If link-code pairing fails or times out, you can scan the terminal QR code to complete authentication.

## Configure custom code

When embedding the runtime using `createClient`, pass `linkCode` in the options object:

```ts
import { createClient } from '@open-wa/wa-automate';
import { PuppeteerDriver } from '@open-wa/driver-puppeteer';

async function start() {
  const client = await createClient({
    sessionId: 'sales',
    driver: new PuppeteerDriver(),
    linkCode: '447123456789',
    headless: true,
  });
}

start().catch(console.error);
```

## Troubleshooting

- Verify that the phone number contains only digits (country code followed by subscriber number).
- Ensure the WhatsApp application on the mobile device is active and has an active network connection.
- If pairing times out, increase `authTimeout` in your configuration or initiate the pairing flow when the host device is immediately accessible.
- If link-code pairing continues to fail, scan the fallback QR code.
