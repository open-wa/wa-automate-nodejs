# Version 5 alpha status

This repository is currently developed on **version 5**, which is in active alpha.

## What alpha status means

- The codebase is structured as a modular monorepo.
- Internal and public APIs may evolve between minor releases.
- Certain legacy v4 flags and helpers are being replaced or redesigned.

**For production stability, use version 4.76.0:**

```bash
npx @open-wa/wa-automate@4.76.0
```

## Choose between version 4 and version 5

| Use version 5 if... | Use version 4 if... |
| --- | --- |
| You are evaluating new features | You run an existing production system |
| You are contributing to open-wa development | You require strict stability guarantees |
| You are starting a new project | You rely on legacy v4 flags and conventions |
| You want to use the plugin SDK or MCP server | You want to avoid breaking changes during upgrades |

## Key changes in version 5

- **Monorepo architecture**: Modular repository containing decoupled packages
- **Pluggable browser drivers**: Support for Puppeteer, Playwright, and Lightpanda via dedicated driver packages
- **`createClient` entry point**: Primary programmatic entry point from `@open-wa/core`
- **Plugin system**: Modular extensions loaded via `plugins` and `pluginConfig`
- **MCP server**: Built-in Model Context Protocol server exposing methods as tools for AI agents
- **Transport architecture**: Uses HTTP RPC for method calls and Server-Sent Events (SSE) for real-time events

## Migrate from version 4

To evaluate version 5 alongside an existing v4 deployment:

1. Start with Easy API and confirm that `http://localhost:8080/api-docs/` connects and serves methods.
2. Test session persistence, authentication, webhooks, and schemas in an isolated test environment.
3. Use `SocketClient` for remote automation rather than embedding browser instances in distributed workers.
4. Use `createClient` when your application requires direct browser lifecycle management.

For complete programmatic setup instructions, see [Custom code](/docs/getting-started/custom-code).
