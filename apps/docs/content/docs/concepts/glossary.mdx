# Glossary

## Chat ID (ChatId)

A unique identifier for a WhatsApp conversation. Direct conversations use the `phone@c.us` format. Group conversations use the `group@g.us` format.

## Contact ID (ContactId)

A chat ID representing an individual contact. It always ends with the `@c.us` domain suffix.

## Driver

The browser automation backend open-wa uses to control WhatsApp Web. Supported drivers include Puppeteer, Playwright, and Lightpanda.

## Easy API

The standalone HTTP server that exposes WhatsApp client actions over REST endpoints. Running `npx @open-wa/wa-automate` starts the Easy API server, serves interactive OpenAPI documentation, and hosts the MCP endpoint.

## Event namespace

The hierarchical naming convention used for runtime events, such as `message.received`, `client.ready`, and `core.stopping`.

## Group chat ID (GroupChatId)

A chat ID representing a WhatsApp group conversation. It always ends with the `@g.us` domain suffix.

## Headless and visible modes

In `headless` mode, Chromium runs in the background without a graphical user interface. In visible (headful) mode, the browser window is displayed on your screen for debugging.

## Host account

The primary WhatsApp account on a mobile device that authenticates and establishes the session.

## License tiers

Licensing levels that govern access to commercial features, including Community, Insiders, and Enterprise tiers.

## Linked device identifier (LID)

An internal identifier used by WhatsApp to route messages across linked companion devices.

## Model Context Protocol (MCP)

An open protocol allowing AI assistants (such as Claude Desktop or Cursor) to discover and invoke tools. open-wa includes a built-in MCP server that maps Easy API methods to AI tools.

## Proxy

An intermediary service that routes network traffic between your application and WhatsApp. Examples include HTTP/SOCKS proxies for outbound requests and the Cloudflare session proxy for inbound remote client access.

## Re-authentication

The automated restoration of an existing session using saved disk credentials without requiring a new QR code scan.

## Re-scan

The action of scanning a new QR code when existing session tokens have expired or been revoked.

## Session

An isolated WhatsApp automation instance identified by a unique `sessionId`.

## Session data

The browser profile data, authentication keys, and cookies stored on disk to maintain session state across process restarts.

## SocketClient

A lightweight client library (`@open-wa/socket-client`) used by Node.js applications to interact with a remote Easy API instance without running a local browser process.

## Tunnel

A secure network bridge (such as Cloudflare Tunnel) that exposes a local service to the internet without opening inbound firewall ports.

## WAPI

The internal JavaScript bridge injected into the WhatsApp Web page context by open-wa to control page state and dispatch events.

## Webhook

An HTTP `POST` request dispatched by open-wa to an external endpoint when incoming messages or lifecycle events occur.
