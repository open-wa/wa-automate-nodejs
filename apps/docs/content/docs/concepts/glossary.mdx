# Glossary

## ChatId

A `ChatId` is the identifier accepted by a chat or messaging method. The current schema accepts a numeric direct-contact JID such as `447700900000@c.us`, a numeric group JID such as `447123456789-1445627445@g.us`, or a numeric LID JID such as `12345678901234@lid`. An incoming event can expose the value through fields such as `from` and `chatId`; preserve that returned value instead of reconstructing it.

## ContactId

A `ContactId` is a chat ID for a direct contact. The schema requires the numeric `@c.us` form, such as `447700900000@c.us`; display names, invite URLs, and guessed LIDs are not contact IDs.

## Driver

A driver is the browser automation library open-wa uses to run WhatsApp. Puppeteer is the default; Lightpanda and Playwright drivers also exist. See [createClient and drivers](/docs/concepts/create-client-and-drivers).

## Easy API

The HTTP server that runs a session and exposes its methods, an event stream and the Neo dashboard. `npx @open-wa/wa-automate` starts it. See [Easy API](/docs/getting-started/easy-api).

## Event namespace

An event namespace is the naming convention used for runtime events, such as `message.received`, `client.ready`, and `core.stopping`.

## GroupChatId

A `GroupChatId` is an assigned WhatsApp group identifier ending in `@g.us`. Keep the full value returned by an event or group method; an invite URL is an invite token and does not become a group ID until a group method resolves it.

## Headless / headful

`headless` means the browser runs without a visible UI. `headful` means the browser window is visible for debugging or manual observation.

## Host account

The WhatsApp account that authenticates and owns the session.

## License

A license key bound to one WhatsApp number unlocks the licensed features for that number, such as starting chats with new numbers, stories and interactive messages. Each method's reference entry says whether it needs one. See [pricing](/docs/licensing/pricing).

## LID

A LID is an opaque WhatsApp identifier ending in `@lid`. The current API schema accepts a numeric value before that suffix. Keep the ID supplied by the runtime; don't derive one from a phone number or assume every incoming LID has the same representation. The [Chat ID primer](/docs/guides/chatid-primer) explains which inputs the current API accepts.

## MCP

MCP means Model Context Protocol. It is a standard for connecting AI
assistants to external tools. When MCP is enabled for an Easy API instance and
configured with its API key, open-wa exposes Easy API methods as MCP tools.

## Proxy

A proxy is a middleman service that forwards traffic between your app and WhatsApp. In open-wa contexts, this can include Cloudflare Session Proxy and SOCKS or HTTP proxies.

## Re-auth

Re-auth brings a session back online from its saved login file without a new QR scan.

## Re-scan

A re-scan is the user action of scanning a fresh QR code after a session can no longer be restored automatically.

## SDK

Running open-wa inside your own Node.js process with `create()`, instead of over HTTP. See [SDK](/docs/getting-started/custom-code).

## Session

A session is a named automation instance. The `sessionId` is the stable identifier you use to distinguish one runtime from another.

## Session data

The encrypted `<sessionId>.data.json` file that holds a linked account's login. With it, a session restarts without a QR scan, so keep it private.

## SocketClient

The Node.js client that connects to a running Easy API and gives you SDK-style methods and listeners without running a browser yourself. See [SocketClient](/docs/guides/socket-client).

## Tunnel

A tunnel, such as Cloudflare Tunnel, exposes a local service through a public
relay URL without requiring an inbound listening port on your machine or
network. The relay URL is still an internet-facing entry point, so apply the
service's authentication and access controls.

## Webhook

A webhook is an HTTP `POST` that open-wa sends to your server when an event happens, such as a new message. See [Receive webhooks](/docs/guides/receive-webhooks).
