# Package overview

The open-wa version 5 monorepo consists of multiple modular packages. Most users need only `@open-wa/wa-automate`, but you can depend on individual packages for granular control.

## Primary packages

| Package | Description |
| --- | --- |
| [`@open-wa/wa-automate`](/docs/getting-started/custom-code) | Primary entry point re-exporting core functionality and the Easy API CLI server |
| [`@open-wa/client`](/docs/getting-started/custom-code) | Type-safe client interface for invoking WhatsApp actions and subscribing to events |
| [`@open-wa/cli`](/docs/guides/configuration-and-cli) | Command-line interface for managing sessions and running the Easy API daemon |
| [`@open-wa/core`](/docs/concepts/how-it-works) | Internal execution engine managing browser drivers, lifecycle stages, and events |

## Choose which package to install

- **Application developers**: Install `@open-wa/wa-automate`.
- **Plugin developers**: Install `@open-wa/plugin-sdk`.
- **Remote consumers**: Install `@open-wa/socket-client`.
- **Media processing utilities**: Install `@open-wa/decrypt`.

## Stability notes

Version 5 is in active alpha development. The primary public packages (`@open-wa/wa-automate`, `@open-wa/socket-client`, and `@open-wa/decrypt`) provide the most stable interfaces. Lower-level driver interfaces and internal engine packages may evolve between alpha releases.

## Browser drivers

open-wa supports multiple browser automation backends through a unified driver interface:

| Package | Description |
| --- | --- |
| `@open-wa/driver-puppeteer` | Standard Chromium automation using Puppeteer |
| `@open-wa/driver-playwright` | High-performance automation using Playwright |
| `@open-wa/driver-lightpanda` | Experimental lightweight browser runtime |

## Utilities and SDKs

| Package | Description |
| --- | --- |
| `@open-wa/plugin-sdk` | Types and helper utilities for building open-wa plugins |
| `@open-wa/session-sync` | Synchronization adapters for remote S3 or compressed storage |
| `@open-wa/screencaster` | Real-time browser canvas streaming |
| `@open-wa/decrypt` | Zero-dependency media decryption utility for WhatsApp attachments |
| `@open-wa/hyperemitter` | Schema-validated typed event emitter powering the runtime |
