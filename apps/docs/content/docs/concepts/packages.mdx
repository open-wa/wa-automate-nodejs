Start with the package that matches where your WhatsApp session will run. You can add integrations and lower-level packages when your application needs them.

| What you want to do | Package and setup guide |
| --- | --- |
| Run a local HTTP API | [`@open-wa/wa-automate`: Easy API quick start](/docs/getting-started/quickstart) |
| Own the browser and session inside a Node.js app | [`@open-wa/wa-automate`: custom code](/docs/getting-started/custom-code) |
| Connect to an Easy API session that is already running | [`@open-wa/socket-client`: remote client setup](/docs/client-and-integrations/socket-client) |
| Build a plugin | [`@open-wa/plugin-sdk`: plugin getting started](/docs/plugins/getting-started) |
| Decrypt downloaded WhatsApp media | [`@open-wa/decrypt`: package reference](/docs/reference/workspaces/packages/decrypt) |

The installation examples use **5.1.0**. See [release status](/docs/releases/v5-alpha) before choosing a different npm tag or Docker image; those release channels can move independently.

## Choose a browser driver

Embedded applications pass a driver to `createClient()`. The [custom-code guide](/docs/getting-started/custom-code) includes a complete Puppeteer example with installation, authentication, message handling, and shutdown.

| Driver package | When to consider it |
| --- | --- |
| [`@open-wa/driver-puppeteer`](/docs/reference/workspaces/packages/driver-puppeteer) | Follow the Puppeteer setup used in the getting-started examples. |
| [`@open-wa/driver-playwright`](/docs/reference/workspaces/packages/driver-playwright) | Use the Playwright adapter when it fits your browser setup. |
| [`@open-wa/driver-lightpanda`](/docs/reference/workspaces/packages/driver-lightpanda) | Explore the experimental Lightpanda adapter and its current limitations. |

## Explore the implementation

Most applications can stay with the entry points above. If you need to work on the runtime itself, the package references describe each workspace:

- [`@open-wa/client`](/docs/reference/workspaces/packages/client) exposes the Client API.
- [`@open-wa/core`](/docs/reference/workspaces/packages/core) coordinates the browser driver and runtime events.
- [`@open-wa/config`](/docs/reference/workspaces/packages/config) loads and validates configuration.
- [`@open-wa/session-sync`](/docs/reference/workspaces/packages/session-sync) handles session synchronization.
- [`@open-wa/screencaster`](/docs/reference/workspaces/packages/screencaster) streams the browser screen to a client.
- [`@open-wa/hyperemitter`](/docs/reference/workspaces/packages/hyperemitter) provides the runtime's schema-based event emitter.

Browse the [workspace reference](/docs/reference/workspaces) for the complete package, application, and integration list.
