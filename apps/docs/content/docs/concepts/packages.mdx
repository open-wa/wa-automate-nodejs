# Choose a package

Most applications need only `@open-wa/wa-automate`. Add another package when
your code runs somewhere other than the session, or when you're building a
plugin.

| What you want to do | Package | Start here |
| --- | --- | --- |
| Run an HTTP server for the session | `@open-wa/wa-automate` | [Easy API](/docs/getting-started/easy-api) |
| Run the session inside a Node.js program | `@open-wa/wa-automate` | [SDK](/docs/getting-started/custom-code) |
| Call a running Easy API from another Node.js service | `@open-wa/socket-client` | [SocketClient](/docs/guides/socket-client) |
| Forward events to your backend over HTTP | `@open-wa/integration-webhook` | [Receive webhooks](/docs/guides/receive-webhooks) |
| Connect a Chatwoot inbox | `@open-wa/integration-chatwoot` | [Chatwoot](/docs/guides/chatwoot) |
| Use WhatsApp from Node-RED flows | `@open-wa/node-red` | [Node-RED](/docs/guides/node-red) |
| Store incoming media in S3 | `@open-wa/integration-s3` | [S3 media](/docs/guides/s3-media) |
| Build a plugin | `@open-wa/plugin-sdk` | [Plugins](/docs/plugins/getting-started) |
| Decrypt downloaded WhatsApp media | `@open-wa/decrypt` | [Media](/docs/guides/media) |

Install packages without a version and npm picks the current release, for
example `npm install @open-wa/wa-automate`. Keep every `@open-wa` package in a
project on the same version. Release notes are on
[GitHub](https://github.com/open-wa/wa-automate-nodejs/releases).

## Browser drivers

`create()` installs and runs Chrome through Puppeteer for you, so you don't
need a driver package for the SDK or Easy API. The driver packages matter only
when you start the runtime yourself with `createClient()`:

| Package | Use |
| --- | --- |
| `@open-wa/driver-puppeteer` | Chrome or Chromium. The default and the best supported. |
| `@open-wa/driver-lightpanda` | The experimental Lightpanda browser. No video, screenshots or rendering. |
| `@open-wa/driver-playwright` | A Playwright adapter for setups that already use Playwright. |

[createClient and drivers](/docs/concepts/create-client-and-drivers) shows how
to pass one.

## Lower-level packages

You don't need these to build on open-wa; they're listed so you know what you're
seeing in a lockfile. `@open-wa/client` holds the client methods,
`@open-wa/core` runs the session and its events, `@open-wa/config` loads and
validates configuration, `@open-wa/session-sync` syncs the saved login to
storage, `@open-wa/screencaster` streams the browser screen, and
`@open-wa/hyperemitter` is the typed event emitter.
