# open-wa / wa-automate

Use this documentation to configure a WhatsApp session and connect it to your application or helpdesk. Consult the API reference for exact method signatures and event schemas.

## What you can build

- Customer support inboxes that sync WhatsApp into your internal tools
- Order, booking, and delivery notifications triggered by backend systems
- Bots that respond to messages, group activity, and runtime events
- Webhook bridges for CRMs, helpdesks, automations, and workflow systems
- Multi-session setups with named accounts and isolated consumers
- AI agent tool surfaces using the built-in Model Context Protocol server

## Prerequisites

- **Node.js**: `>= 22.21.1`
- **npm** for published packages, or **pnpm 11.9.0** for repository development
- A WhatsApp account on a mobile device that remains connected to the internet

## v5 alpha status

<Callout type="warning">
Version 5 is in alpha. Use version 4 (`4.76.0`) for production systems unless you are actively testing v5.
</Callout>

The current stable release is **v4.76.0**. Version 5 is published under the `alpha` dist-tag:

```bash
# Production: use v4
npx @open-wa/wa-automate@4.76.0

# Testing: use the v5 alpha release
npx @open-wa/wa-automate@alpha
```

### What changed in v5

- Modular monorepo architecture with decoupled packages
- Pluggable browser drivers (`@open-wa/driver-puppeteer`, `@open-wa/driver-playwright`, `@open-wa/driver-lightpanda`)
- `createClient` as the primary programmatic entry point
- Plugin system and SDK (`@open-wa/plugin-sdk`) for modular extensions
- Built-in MCP server for AI agent tool integration

### Choose between v4 and v5

- **v4**: Choose this version for production systems, existing deployments, and stable integrations.
- **v5**: Choose this version to evaluate new features, contribute to development, or build new projects tracking alpha updates.

## Start here

- **[Quickstart](/docs/getting-started/quickstart)**: Start the API server, authenticate your account, and send your first message.
- **[Custom code](/docs/getting-started/custom-code)**: Embed the library directly into your Node.js application using `createClient`.
- **[SocketClient](/docs/client-and-integrations/socket-client)**: Connect a remote application to a running Easy API instance.
- **[Cloudflare session proxy](/docs/client-and-integrations/cf-proxy)**: Access a session remotely without exposing inbound local ports.

## Documentation structure

- **Getting started**: First-run guides covering Quickstart, Easy API, Docker, custom code, and link-code authentication.
- **Guides**: Practical walkthroughs for configuration, events, sessions, messages, media, and groups.

- **Concepts**: Architectural model, data structures, and core terminology.
- **API reference**: Generated documentation covering all exported methods, classes, and types.
