# open-wa

open-wa is a self-hosted WhatsApp API and Node.js library. You link a normal
WhatsApp account, then send and receive messages from your own code, over HTTP
or in-process.

```bash
npm init @open-wa@latest my-bot
```

Choose **Easy API** to send HTTP requests from any language, or **SDK** to
write the bot in Node.js. The [quick start](/docs/getting-started/quickstart)
takes you from that command to your first message. You need Node.js 22.21.1 or
newer and a phone with WhatsApp.

## What you can build

- [Send one-time codes](/docs/build/send-otp) to customers who asked for them.
- [Confirm bookings with buttons](/docs/build/booking-confirmation) and act on
  the reply.
- [Run a support bot](/docs/build/support-bot) that answers common questions
  and hands over to a person.
- [Forward messages to your backend](/docs/guides/receive-webhooks), CRM or
  helpdesk.

## How these docs are organised

- **Build**: complete recipes for common jobs.
- **Getting started**: quick start, Easy API, SDK, Docker and link-code login.
- **Guides**: sending, receiving, integrations and configuration.
- **Sessions and login**: QR codes, link codes, session events and recovery.
- **Concepts**: how a session runs, packages and terms.
- **Plugins**: extend a running session with your own code.
- **API reference**: every method, with SDK, SocketClient and HTTP examples.
- **Operations**: the production checklist, security, limits and errors.
- **Licensing**: prices and what a license unlocks.
- **Upgrading**: moving from v4 and the
  [release notes on GitHub](https://github.com/open-wa/wa-automate-nodejs/releases).

Already running a session elsewhere? Use [SocketClient](/docs/guides/socket-client)
from Node.js, or reach it without opening a port through the
[Cloudflare session proxy](/docs/guides/cf-proxy).
