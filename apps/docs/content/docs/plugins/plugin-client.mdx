# PluginClient reference

`PluginClient` provides a transport-agnostic client proxy for invoking WhatsApp methods within a plugin. Plugins communicate through the host runtime transport rather than accessing the Chrome DevTools Protocol (CDP) or the browser DOM directly.

## What PluginClient provides

- A typed client proxy forwarding commands to the active session runtime
- Access via the `client` property in `PluginInput`
- Transport-independent execution across HTTP RPC and Server-Sent Events (SSE)
- Generic method execution via `ask()` and typed convenience methods

## Limitations and security boundaries

- No raw browser DOM or CDP execution
- No direct arbitrary local file system access
- Operations execute within security-filtered runtime boundaries

## Generic method invocation

### `ask(method, args?)`

Invokes any supported WhatsApp client method by name:

```ts
// Send a text message
const messageId = await client.ask<string>('sendText', ['447700900000@c.us', 'Hello']);

// Query the host account phone number
const hostNumber = await client.ask<string>('getHostNumber');

// Fetch contact details
const contact = await client.ask('getContact', ['447700900000@c.us']);
```

**Parameters:**

- `method` (`string`): The target client method name (for example, `'sendText'`, `'sendImage'`, `'getHostNumber'`)
- `args` (`unknown[] | Record<string, unknown>`): Optional array or object of method arguments

**Returns:** `Promise<T>` resolving to the method response payload.

## Event listener methods

### `listen(listener, callback)`

Registers a listener for WhatsApp events:

```ts
const subscriptionId = await client.listen('onMessage', (data) => {
  console.log('Received message:', data);
});
```

**Parameters:**

- `listener` (`string`): Event name (for example, `'onMessage'`, `'onAnyMessage'`)
- `callback` (`(data: unknown) => void`): Callback receiving event payloads

**Returns:** `Promise<string>` resolving to a unique subscription identifier.

## Convenience automation methods

Convenience methods provide typed wrappers around `ask()` for common operations:

### `sendText(to, content)`

Sends a plain text message:

```ts
const messageId = await client.sendText('447700900000@c.us', 'Hello!');
```

**Returns:** `Promise<string>` resolving to the generated message ID.

### `sendImage(to, url, filename, caption?)`

Sends an image from an accessible HTTP URL:

```ts
const messageId = await client.sendImage(
  '447700900000@c.us',
  'https://example.com/image.jpg',
  'image.jpg',
  'Sample image caption'
);
```

### `sendFile(to, base64, filename, caption?)`

Sends a binary file encoded as a base64 data URI:

```ts
const messageId = await client.sendFile(
  '447700900000@c.us',
  'data:application/pdf;base64,JVBERi0...',
  'document.pdf',
  'Attached invoice'
);
```

### `sendLocation(to, lat, lng, text?)`

Sends a geographic location pin:

```ts
await client.sendLocation('447700900000@c.us', '51.5074', '-0.1278', 'London Office');
```

### `sendLinkWithAutoPreview(to, url, text)`

Sends a URL with rich link preview metadata:

```ts
await client.sendLinkWithAutoPreview(
  '447700900000@c.us',
  'https://example.com',
  'Check our documentation'
);
```

### `reply(to, content, quotedMsgId)`

Replies directly to an existing message:

```ts
await client.reply('447700900000@c.us', 'Acknowledged.', originalMessageId);
```

### `decryptMedia(message)`

Decrypts binary attachment data from an incoming media message:

```ts
const base64Data = await client.decryptMedia(message);
```

### `getHostNumber()`

Retrieves the phone number of the authenticated WhatsApp account:

```ts
const hostNumber = await client.getHostNumber();
```

### `getContact(contactId)`

Retrieves profile and contact metadata for a given contact ID:

```ts
const contact = await client.getContact('447700900000@c.us');
```

### `getAllContacts()`

Retrieves an array of all contacts stored in the current session:

```ts
const contacts = await client.getAllContacts();
```

### `getAllChats()`

Retrieves all active chat conversations:

```ts
const chats = await client.getAllChats();
```

### `sendSeen(chatId)`

Marks unread messages in a chat as read (sending blue read receipts):

```ts
const success = await client.sendSeen('447700900000@c.us');
```

**Returns:** `Promise<boolean>`

## Dynamic proxy fallback

Any valid WhatsApp client method not explicitly typed on the interface is forwarded dynamically to the host runtime:

```ts
await client.setProfileName('Support Desk');
```
