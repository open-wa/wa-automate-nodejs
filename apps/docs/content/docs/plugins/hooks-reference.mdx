# Hooks reference

Plugin hooks connect your custom logic to the open-wa execution lifecycle. Return a handlers object from your plugin's `init()` method to register the hooks your integration requires.

All hooks are optional.

## Lifecycle hooks

### `core.starting`

Dispatched when the open-wa runtime starts initialization.

```ts
'core.starting': async ({ config }) => {
  logger.info('Session initializing');
};
```

**Payload:** `{ config: unknown }` containing global configuration properties.

### `core.started`

Dispatched once the session reaches full operational readiness.

```ts
'core.started': async () => {
  logger.info('Session ready');
};
```

### `core.stopping`

Dispatched when the host initiates runtime shutdown.

```ts
'core.stopping': async ({ reason }) => {
  logger.info('Session stopping', { reason });
};
```

**Payload:** `{ reason?: string }` describing the shutdown cause.

### `client.ready`

Dispatched when the WhatsApp client completes connection and authentication.

```ts
'client.ready': async ({ sessionId }) => {
  logger.info('WhatsApp client connected', { sessionId });
};
```

**Payload:** `{ sessionId: string }` containing the current session identifier.

## Authentication hooks

### `auth.qr`

Dispatched when a new QR code is generated for pairing.

```ts
'auth.qr': async ({ sessionId, qr, attempt }) => {
  logger.info('QR code emitted', { sessionId, attempt });
};
```

**Payload:**

- `sessionId` (`string`): Active session ID
- `qr` (`string`): Raw QR code data string
- `attempt` (`number`): Monotonically increasing attempt counter

### `auth.authenticated`

Dispatched when credentials verify successfully.

```ts
'auth.authenticated': async ({ sessionId }) => {
  logger.info('Session authenticated', { sessionId });
};
```

**Payload:** `{ sessionId: string }`

## Message hooks

### `message.received`

Dispatched when an incoming message arrives.

```ts
function parseTextMessage(message: unknown) {
  if (!message || typeof message !== 'object') return null;

  const candidate = message as { body?: unknown; from?: unknown; type?: unknown };
  if (candidate.type !== 'chat') return null;
  if (typeof candidate.body !== 'string' || typeof candidate.from !== 'string') {
    return null;
  }

  return { body: candidate.body, from: candidate.from, type: 'chat' };
}

'message.received': async ({ message }) => {
  const msg = parseTextMessage(message);
  if (!msg) return;

  logger.info('Text message received', { from: msg.from });
};
```

**Payload:** `{ message: unknown }` representing the incoming WhatsApp message object.

Inspect the `type` property to identify message kinds:

- `'chat'`: Plain text conversation
- `'image'`: Photo attachment
- `'video'`: Video clip
- `'audio'`: Voice note or audio file
- `'document'`: Generic file attachment
- `'sticker'`: WhatsApp sticker
- `'location'`: Geographic coordinate pin

### `message.sent`

Dispatched when the local session sends a message.

```ts
'message.sent': async ({ message }) => {
  logger.info('Message dispatched', { message });
};
```

**Payload:** `{ message: unknown }`

### `message.ack`

Dispatched when message delivery status updates.

```ts
'message.ack': async ({ messageId, ack }) => {
  logger.info('Message acknowledged', { messageId, ack });
};
```

**Payload:**

- `messageId` (`string`): Message identifier
- `ack` (`number`): WhatsApp acknowledgment status code (`1` = sent, `2` = delivered, `3` = read)

## Message interceptors

### `message.send.before`

Invoked **before** dispatching an outgoing message. Use this interceptor to mutate message content or halt dispatch.

```ts
'message.send.before': async (
  input: { to: string; content: unknown },
  output: { content: unknown; metadata?: Record<string, unknown> }
) => {
  if (typeof output.content === 'string') {
    output.content = output.content.trim();
  }
};
```

**Input:** `{ to: string; content: unknown }`
**Output:** `{ content: unknown; metadata?: Record<string, unknown> }`

To prevent sending, throw an error from the hook.

### `message.send.after`

Invoked **after** an outgoing message is dispatched.

```ts
'message.send.after': async (
  input: { messageId: string; to: string },
  output: { metadata?: Record<string, unknown> }
) => {
  output.metadata = { sentAt: Date.now() };
};
```

**Input:** `{ messageId: string; to: string }`
**Output:** `{ metadata?: Record<string, unknown> }`

## Custom API routes (routes)

Mount custom HTTP routes using a Hono sub-application under `/plugins/<plugin-name>/`:

```ts
import { Hono } from 'hono';

routes: () => {
  const app = new Hono();

  app.get('/status', (c) => {
    return c.json({ status: 'ok' });
  });

  app.post('/webhook', async (c) => {
    const body = await c.req.json();
    return c.json({ received: true });
  });

  return app;
};
```

## Web dashboard pages (pages)

Declare custom panels to render in the web dashboard navigation sidebar:

```ts
pages: [
  {
    path: '/',
    title: 'Plugin Status',
    icon: 'Activity',
    order: 1,
    description: 'Current plugin status and metrics',
  },
];
```

## Model Context Protocol tools (tool)

Register structured tools callable by connected AI assistants:

```ts
init: async ({ client }) => ({
  tool: {
    sendGreeting: {
      description: 'Send a greeting message to a contact',
      args: {
        chatId: z.string().describe('Target WhatsApp chat ID'),
        name: z.string().describe('Recipient name'),
      },
      execute: async (args, context) => {
        if (typeof args.chatId !== 'string' || typeof args.name !== 'string') {
          return 'Invalid arguments: chatId and name must be strings';
        }

        await client.sendText(
          args.chatId,
          `Hello, ${args.name}!`
        );
        context.logger.info('Greeting sent', { sessionId: context.sessionId });
        return `Greeting successfully delivered to ${args.chatId}`;
      },
    },
  },
});
```

## Resource disposal (dispose)

Invoked during shutdown to release external resources:

```ts
dispose: async () => {
  // Close database connections and flush in-flight queues
  logger.info('Plugin resources cleaned up');
};
```

## Catch-all event hook (event)

Subscribes to all public events dispatched across the runtime:

```ts
event: async ({ event, payload }) => {
  logger.debug('Runtime event dispatched', { event, payload });
};
```

**Input:** `{ event: string; payload: unknown }`
