# Messages and message events

Use this guide to handle core messaging workflows: subscribing to incoming messages, dispatching replies, attaching rich media, and handling message delivery events.

For chat identifier formatting (such as phone numbers, group IDs, and LIDs), see the [ChatId primer](/docs/guides/chatid-primer).

## Receive incoming messages

Register event listeners on the client instance to capture message payloads:

```ts
// Capture incoming messages from other contacts or groups
client.onMessage((message) => {
  console.log('Incoming message body:', message.body);
});

// Capture all messages including outgoing messages sent from the active account
client.onAnyMessage((message) => {
  console.log('Message event:', message.id, message.body);
});
```

## Message object shape

Incoming message payloads contain message text, participant identifiers, media metadata, and quote context:

```ts
client.onMessage((message) => {
  console.log('Message ID:', message.id);
  console.log('From chat ID:', message.from);
  console.log('Message body:', message.body);
  console.log('Message type:', message.type);
});
```

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Unique WhatsApp message identifier |
| `body` | `string` | Plain text content |
| `type` | `string` | Message kind (`chat`, `image`, `video`, `document`, `ptt`, `location`, `buttons_response`, `list_response`) |
| `from` | `string` | Sender chat ID (contact ID for direct chats, group ID for group chats) |
| `to` | `string` | Recipient chat ID |
| `chatId` | `string` | Conversation thread identifier |
| `sender` | `object` | Sender contact object |
| `author` | `string` | Participant contact ID who sent the message within a group chat |
| `fromMe` | `boolean` | `true` if the message was sent by the authenticated account |
| `timestamp` | `number` | Unix timestamp in seconds |
| `isGroupMsg` | `boolean` | `true` if the message originates from a group chat |
| `isMedia` | `boolean` | `true` if the message contains a media attachment |
| `caption` | `string` | Caption accompanying an image, video, or document |
| `mentionedJidList` | `string[]` | Array of contact IDs tagged in the message |
| `ack` | `number` | Delivery state (`1` = sent, `2` = delivered, `3` = read) |
| `quotedMsg` | `object` | Quoted message object if replying to another message |

## Send text messages

```ts
const chatId = '447700900000@c.us';

// Dispatch a standard text message
await client.sendText(chatId, 'Hello from open-wa');

// Dispatch text with tagged user mentions
await client.sendTextWithMentions(chatId, 'Hello @447700900000');

// Dispatch a quoted reply to an existing message
await client.reply(chatId, 'Acknowledged.', MESSAGE_ID);
```

Always `await` client methods to catch runtime exceptions and validation errors.

## Formatting text messages

WhatsApp renders inline markdown formatting:

```ts
await client.sendText(chatId, '*bold text*');
await client.sendText(chatId, '_italic text_');
await client.sendText(chatId, '~strikethrough text~');
await client.sendText(chatId, '```monospace code block```');
await client.sendText(chatId, 'Order *CONFIRMED* for _tomorrow_.');
```

## Media attachments and text differences

To send images, documents, audio clips, or videos, pass a base64 Data URL along with the target filename:

```ts
// Send an image with a caption
await client.sendImage(
  chatId,
  'data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA...',
  'receipt.png',
  'Monthly billing receipt'
);

// Send a PDF document
await client.sendFile(
  chatId,
  'data:application/pdf;base64,JVBERi0xLjQK...',
  'statement.pdf',
  'Account statement'
);
```

## Quoted replies

Use `reply` to quote a prior message directly in the chat thread:

```ts
client.onMessage(async (message) => {
  if (message.body === '!status') {
    await client.reply(message.from, 'Systems operational.', message.id);
  }
});
```

## User mentions

Mention participants in group conversations by passing their contact ID:

```ts
const groupId = '120363024567890123@g.us';

await client.sendTextWithMentions(
  groupId,
  'Attention @447700900000, please review this task.',
  false,
  ['447700900000@c.us']
);
```

```ts

await client.sendButtons(
  chatId,
```

## Read receipts and typing simulation

```ts
// Monitor delivery confirmations
client.onAck((ack) => {
  console.log('Message ACK state:', ack.id, ack.ack);
});

// Indicate typing state in chat
await client.simulateTyping(chatId, true);
await client.simulateTyping(chatId, false);
```

## Error handling

```ts
try {
  const result = await client.sendText(chatId, 'Hello');
  if (!result) {
    console.warn('Message dispatch did not return an identifier');
  }
} catch (error) {
  console.error('Failed to dispatch message:', error);
}
```

| Issue | Resolution |
| --- | --- |
| Invalid chat ID format | Verify the ID ends in `@c.us`, `@g.us`, or `@lid`. See [ChatId primer](/docs/guides/chatid-primer). |
| Session not ready | Await client readiness before sending messages. |
| Temporary WhatsApp block | If sending fails with rate limits or spam restrictions, back off traffic and inspect session status. |
| Media payload rejected | Ensure the base64 Data URL format includes valid MIME headers and data encoding. |

## Complete bot example

```ts
import { createClient } from '@open-wa/wa-automate';
import { PuppeteerDriver } from '@open-wa/driver-puppeteer';
import { Client } from '@open-wa/client';

async function main() {
  const openwa = await createClient({
    sessionId: 'bot-session',
    driver: new PuppeteerDriver(),
    headless: true,
  });

  const client = new Client({
    client: openwa,
    transport: openwa.getTransport(),
  });
  await client.start();

  client.onMessage(async (message) => {
    try {
      if (message.body === '!ping') {
        await client.reply(message.from, 'pong', message.id);
        return;
      }

      if (message.body === '!help') {
        await client.sendText(
          message.from,
          '*Available commands*\n• `!ping` - Test connection\n• `!info` - Session information'
        );
        return;
      }
    } catch (error) {
      console.error('Error handling incoming message:', error);
    }
  });
}

main().catch(console.error);
```
