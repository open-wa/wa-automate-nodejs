# Groups

WhatsApp assigns group IDs, so keep the full ID that a method or message gives you rather than building one from a name or participant numbers. The [chat ID primer](/docs/guides/chatid-primer) covers ID formats and invite links. The examples assume a `client` from `create()`.

## Create a group

`createGroup` needs a [license](/docs/licensing/pricing). It returns an object with the new group's `gid`, or `null` if no group was created. The account must also be allowed to add each contact you list.

```ts
const created = await client.createGroup('Support updates', ['447700900000@c.us']);
if (!created?.gid) throw new Error('The group was not created');

const groupId = created.gid;
```

## Manage participants

`addParticipant`, `removeParticipant`, `promoteParticipant` and `demoteParticipant` change one participant at a time. They need the account to be a group admin, and each returns `true` only when the change succeeded.

```ts
const added = await client.addParticipant(groupId, '447700900000@c.us');
if (!added) console.error('The participant was not added');
```

The [group method reference](/docs/reference/client/groups#addparticipant) lists the exact signatures. To act only on messages from certain groups, see [group filtering](/docs/guides/group-filtering).

## Invite links

`getGroupInviteLink` returns a link that lets people join; the link isn't the group ID. `revokeGroupInviteLink` invalidates the current link so you can share a new one. Joining a group through a link with `joinGroupViaLink` needs a [license](/docs/licensing/pricing) and resolves to the group ID on success.

```ts
const inviteUrl = await client.getGroupInviteLink(groupId);
const result = await client.joinGroupViaLink(inviteUrl);

if (typeof result === 'string') console.log('Joined group:', result);
else console.error('The invite did not return a group ID:', result);
```

Over the Easy API, `joinGroupViaLink` also accepts `returnChatObj` to return the chat instead of the ID.

## Read and change group details

`getGroupInfo`, `getGroupMembers`, `getGroupAdmins`, `setGroupTitle`, `setGroupDescription`, `setGroupIcon` and the admin-only settings are listed in the [group method reference](/docs/reference/client/groups), with their Easy API routes.

## React to membership changes

`onParticipantsChanged` watches one group, and `onGlobalParticipantsChanged` watches every group the account is in:

```ts
client.onGlobalParticipantsChanged((change) => {
  console.log(change.groupId, change.action, change.participantIds, change.by);
});
```

`action` is one of `add`, `remove`, `promote`, `demote`, `invite` or `leave`, and `by` is the participant who made the change when it's known. Each callback describes one change rather than the full member list, so keep your own record of a group if later steps depend on who is in it. Over HTTP, the same change arrives as the `group.participants.changed.global` event; see [receive messages](/docs/guides/receive-messages).
