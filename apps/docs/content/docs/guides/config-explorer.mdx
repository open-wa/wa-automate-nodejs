# Config explorer

Every setting can go in a config file such as `wa.config.ts`. Some also have a CLI flag, and most have a `WA_*` environment variable. Search for a setting, filter by group, and switch between the three forms; the table and snippet update to match. A setting marked `config file only` has no flag or variable in the form you picked, and nested settings show their full path.

For full types and defaults, see [every setting](/docs/guides/configuration-and-cli#every-setting).

<ConfigExplorer />

<Callout type="info">
For example, `mcp.enabled` is a nested config-file setting, while `WA_MCP` sets the whole `mcp` object as JSON. The CLI does not parse `--mcp`. Some flags also have short forms, such as `-p` for `--port`.
</Callout>
