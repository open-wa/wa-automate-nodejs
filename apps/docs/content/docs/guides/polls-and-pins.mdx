# Polls and pinned messages

Polls and pins need no license. The examples assume a `client` from `create()`.

## Create a poll

```ts
const pollId = await client.sendPoll(chatId, 'Which day?', ['Friday', 'Saturday', 'Sunday'], {
  selectableCount: 1,
  endTime: Date.now() + 60 * 60 * 1000,
  hideVoterNames: true,
  quotedMsgId: messageId,
});
```

`selectableCount` defaults to 1, and `0` lets people pick every option. Options must be non-empty and unique, and WhatsApp's own limits on option count and text length apply. `endTime` is in **Unix milliseconds** and must be in the future; note that [calendar events](/docs/guides/whatsapp-events) use seconds instead.

Closing times and hidden voter names only work when WhatsApp allows them for the account and chat. If it doesn't, `sendPoll` throws rather than quietly dropping the option. `hideVoterNames` controls what WhatsApp shows; it isn't anonymity, but open-wa does leave individual votes out of the results for these polls.

## Read results and vote

```ts
if (typeof pollId === 'string') {
  const results = await client.getPollResults(pollId);
  console.log(results.options); // [{ id, name, count }, ...]
  await client.voteOnPoll(pollId, [results.options[0].id]);
  await client.voteOnPoll(pollId, []); // Remove this account's vote.
}
```

Vote with the option IDs from the results rather than matching on the text. `voteOnPoll` rejects duplicate or unknown options, too many selections and closed polls, and `true` means the vote was submitted, not delivered.

Results come from the votes this session has synced (`scope: 'synced'`), so a vote that hasn't arrived yet can be missing. Polls work in direct chats and groups; channel polls aren't supported by these methods.

## Listen for votes

```ts
const listener = client.onPollVote(async (vote) => {
  console.log(vote.pollId, vote.selectedOptionIds);
  const results = await client.getPollResults(vote.pollId);
  console.log(results.voterCount, results.options);
});

// When you no longer need it:
listener.off();
```

The listener also reports this account's own votes and can replay votes while chat history loads, so deduplicate by `id` and `timestamp` and use `getPollResults` for the current totals. On hidden-voter polls, votes have no `id` or `senderId`. A removed vote has an empty `selectedOptionIds` array.

## Pin a message

```ts
await client.pinMessage(messageId); // Seven days by default.
await client.pinMessage(messageId, 'OneDay');
await client.pinMessage(messageId, 'ThirtyDays');
await client.unpinMessage(messageId);
```

A pinned message shows at the top of the conversation for everyone, and the account needs permission to pin in that chat. `pinChat(chatId)` and `unpinChat(chatId)` are different: they only move a chat in this account's own chat list.
