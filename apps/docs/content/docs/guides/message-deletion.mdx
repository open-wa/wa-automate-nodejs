# Delete messages

`deleteMessage(chatId, messageId, onlyLocal?)` takes a chat ID, one message ID or an array of them, and an optional `onlyLocal` flag. It resolves to `true` when open-wa finished the deletion and `false` when the chat couldn't be found. It also resolves to `true` when none of the IDs match a loaded message, so `true` on its own doesn't prove a message was removed, and even a completed delete for everyone can't prove every recipient's copy is gone.

## Delete for everyone or only here

By default (`onlyLocal: false`), messages this account sent are deleted for everyone, and incoming messages are deleted from this account only. Deleting for everyone only works within WhatsApp's own limits on who sent the message, group permissions and message age.

```ts
const messageId = await client.sendText('447700900000@c.us', 'This message may be removed shortly.');

const deleted = await client.deleteMessage('447700900000@c.us', messageId);
if (!deleted) console.error('The deletion did not complete; check the chat and message IDs');
```

`sendText` returns a message ID you can pass straight to `deleteMessage`. Use IDs from send results and message events rather than building them yourself.

Set `onlyLocal: true` to remove a message from this account's view only. It stays on other devices and with recipients.

```ts
await client.deleteMessage('447700900000@c.us', 'false_447700900000@c.us_ABC123', true);
```

## Delete from a message handler

You can delete from a handler, but WhatsApp may refuse to delete other people's messages for everyone unless the account is a group admin, and older messages can be past the time limit. Keep the failure path explicit:

```ts
client.onMessage(async (message) => {
  if (!message.body.includes('[remove]')) return;

  try {
    const deleted = await client.deleteMessage(message.chatId, message.id, false);
    if (!deleted) console.warn('Deletion was refused', { chatId: message.chatId, messageId: message.id });
  } catch (error) {
    console.error('Deletion failed', error);
  }
});
```

Deleting can't undo someone having already seen, copied or saved the message. If your policy needs immediate redaction, remove your own stored copy and stop any downstream processing straight away rather than waiting on the result.
