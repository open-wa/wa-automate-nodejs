# Phone number sharing

Some contacts reach you through a LID chat, where their phone number is hidden. You can ask them to share it, or share this account's number with them.

```ts
const requestId = await client.requestPhoneNumber('123456789012345@lid');
// Only when you mean to disclose this account's own number:
const shareId = await client.sharePhoneNumber('123456789012345@lid');
```

`requestPhoneNumber` sends WhatsApp's share-number request to a direct chat. The recipient decides whether to share; the request can't look up or reveal a hidden number.

`sharePhoneNumber` shares the signed-in account's own number with that contact. It takes only the destination, so it can never disclose any other number.

Both return the message ID. Use `onAck` for delivery, and treat the recipient's reply to a request as a separate event. Check the chat before retrying an uncertain send.
