# Chat IDs

Every open-wa method addresses a conversation by its chat ID. When a message or lookup gives you an ID, reuse it exactly; build one from a phone number only when you're messaging a person directly.

## ID formats

| Form | Meaning | Example |
|---|---|---|
| `<digits>@c.us` | A person, by phone number | `447700900000@c.us` |
| `<digits>(-<digits>)?@g.us` | A group | `447123456789-1445627445@g.us` |
| `<digits>@lid` | A person whose phone number is hidden | `12345678901234@lid` |

A LID is an opaque identifier. You can't derive one from a phone number or a phone number from one, so pass it through unchanged.

## Turn a phone number into a chat ID

Use the country code, drop the `+`, spaces, dashes and brackets, then add `@c.us`:

```ts
function phoneToChatId(phone: string): string {
  return `${phone.replace(/\D/g, '')}@c.us`;
}

phoneToChatId('+44 7700 900000'); // '447700900000@c.us'
```

Methods also accept bare digits and guess the type from the length, but the guess can be wrong, so add the suffix yourself whenever you know it.

## Group IDs

WhatsApp assigns group IDs. Keep the full value from `message.from`, `message.chatId` or a group method, and never rebuild one from a group name or its members.

```ts
client.onMessage((message) => {
  if (message.isGroupMsg) console.log('Group ID:', message.chatId);
});
```

An invite link isn't a group ID. To join from a link, pass it to [`joinGroupViaLink`](/docs/reference/client/groups#joingroupvialink), which needs a license and returns the group ID when it succeeds:

```ts
const result = await client.joinGroupViaLink('https://chat.whatsapp.com/REDACTED_INVITE_TOKEN');
if (typeof result === 'string') console.log('Joined group:', result);
else console.error('The invite could not be used:', result);
```

## IDs on incoming messages

Messages carry the conversation in `from` and `chatId`:

```json
{ "from": "447700900000@c.us", "chatId": "447700900000@c.us", "isGroupMsg": false }
```

```json
{ "from": "447123456789-1445627445@g.us", "chatId": "447123456789-1445627445@g.us", "isGroupMsg": true }
```

When `from` ends in `@lid`, reply to that exact value. Don't split it or try to recover a phone number from it; if you need the number, ask the person with [`requestPhoneNumber`](/docs/guides/phone-number-sharing).

## Common mistakes

| Mistake | Wrong | Correct |
|---|---|---|
| Missing country code | `7700900000@c.us` | `447700900000@c.us` |
| Wrong suffix for a person | `447700900000@g.us` | `447700900000@c.us` |
| Display name instead of ID | `John Doe@c.us` | `447700900000@c.us` |
| Keeping the `+` | `+447700900000@c.us` | `447700900000@c.us` |
| Using an invite link as a group ID | `ABCdef...@g.us` | Join with `joinGroupViaLink` |
| Guessing an ID | A made-up LID or group ID | Reuse the ID you received |
