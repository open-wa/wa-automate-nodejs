# Media handling and decryption

This guide explains how to dispatch media attachments and decrypt incoming media payloads received from WhatsApp.

## Send files and media

Use domain client methods to dispatch media to conversations:

```ts
const chatId = '447700900000@c.us';

// Dispatch photo attachments
await client.sendImage(chatId, dataUrl, 'photo.jpg', 'Item snapshot');

// Dispatch voice notes (Push to Talk)
await client.sendPtt(chatId, dataUrl);

// Dispatch documents (PDFs, spreadsheets, text files)
await client.sendFile(chatId, dataUrl, 'invoice.pdf', 'Monthly invoice');

// Dispatch media directly from a remote HTTP URL
await client.sendFileFromUrl(chatId, 'https://cdn.example.com/assets/report.pdf');

// Dispatch custom stickers
await client.sendImageAsSticker(chatId, dataUrl);
```

## Data URL generation

Media methods accept base64 Data URLs encoding both the file MIME type and the raw binary payload:

```text
data:<MIME_TYPE>;base64,<BASE64_DATA>
```

Construct Data URLs in Node.js using `fs/promises`:

```ts
import { readFile } from 'node:fs/promises';

const buffer = await readFile('./photo.jpg');
const dataUrl = `data:image/jpeg;base64,${buffer.toString('base64')}`;

await client.sendImage('447700900000@c.us', dataUrl, 'photo.jpg', 'Product image');
```

## MIME type guidelines

WhatsApp validates file types based on the declared MIME type and file extension:

| Media kind | Recommended MIME types | Target methods |
| --- | --- | --- |
| Images | `image/jpeg`, `image/png`, `image/webp` | `sendImage` |
| Animated GIFs | `image/gif` | `sendVideoAsGif` |
| Video clips | `video/mp4`, `video/quicktime` | `sendFile`, `sendVideoAsGif` |
| Voice notes | `audio/ogg; codecs=opus` | `sendPtt` |
| Audio files | `audio/mpeg`, `audio/mp4`, `audio/ogg` | `sendAudio`, `sendFile` |
| Documents | `application/pdf`, `text/plain`, `application/zip` | `sendFile` |
| Stickers | `image/webp`, `image/png` | `sendImageAsSticker` |

## Remote URL authentication

When dispatching media from private CDNs or authenticated APIs, pass custom HTTP request headers to `sendFileFromUrl`:

```ts
await client.sendFileFromUrl(
  '447700900000@c.us',
  'https://api.example.com/v1/invoices/9876.pdf',
  'invoice-9876.pdf',
  'Invoice 9876',
  {
    Authorization: `Bearer ${process.env.FILE_API_TOKEN}`,
  }
);
```

## File size constraints

| Media category | Recommended limit | Notes |
| --- | --- | --- |
| Images & Photos | Up to 16 MB | Automatic compression applied by WhatsApp |
| Video clips | Up to 16 MB | Use MP4 encoding for maximum device compatibility |
| Voice notes & Audio | Up to 16 MB | Opus audio format in OGG container |
| Stickers | Up to 1 MB | 512x512 square WebP format |
| Generic Documents | Up to 100 MB | Large attachments require adequate host RAM |

## Decrypt incoming media

Incoming WhatsApp media files are encrypted end-to-end. Decrypt them to access the raw binary bytes:

```ts
import { decryptMedia } from '@open-wa/decrypt';

client.onMessage(async (message) => {
  if (!message.isMedia || !message.mimetype) return;

  const buffer = await decryptMedia(message);
  console.log(`Decrypted ${buffer.length} bytes for message ${message.id}`);
});
```

## Persistent storage examples

### Save media to local disk

```ts
import { mkdir, writeFile } from 'node:fs/promises';
import path from 'node:path';
import mime from 'mime-types';
import { decryptMedia } from '@open-wa/decrypt';

client.onMessage(async (message) => {
  if (!message.isMedia || !message.mimetype) return;

  const buffer = await decryptMedia(message);
  const extension = mime.extension(message.mimetype) || 'bin';
  const filename = `${message.id}.${extension}`;
  const outputPath = path.join('media', filename);

  await mkdir('media', { recursive: true });
  await writeFile(outputPath, buffer);
  console.log(`Saved media to ${outputPath}`);
});
```

### Stream media to Amazon S3 or Cloudflare R2

```ts
import { PutObjectCommand, S3Client } from '@aws-sdk/client-s3';
import { decryptMedia } from '@open-wa/decrypt';

const s3 = new S3Client({ region: 'us-east-1' });

client.onMessage(async (message) => {
  if (!message.isMedia || !message.mimetype) return;

  const buffer = await decryptMedia(message);
  const key = `inbox/${message.id}`;

  await s3.send(
    new PutObjectCommand({
      Bucket: process.env.MEDIA_BUCKET,
      Key: key,
      Body: buffer,
      ContentType: message.mimetype,
    })
  );
  console.log(`Uploaded media to S3: ${key}`);
});
```

## Stale media recovery and caching

WhatsApp server URLs for media attachments expire over time. If a media message is not decrypted immediately upon arrival:

- Media URLs may return HTTP 404/410 errors.
- Decrypt calls on historic messages may fail.

**Best Practice**: Decrypt incoming media immediately upon receipt and archive the resulting buffers to durable object storage (e.g. S3, Cloudflare R2, or disk).
