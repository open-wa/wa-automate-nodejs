# Calendar events


## `sendEvent`

Send a native WhatsApp event with Unix-second times. Returns its submitted message ID; delivery is observed through ACKs.

```ts
client.sendEvent(
  to: string,
  event: { callType?: "voice" | "video"; description?: string; endTime?: number; extraGuestsAllowed?: boolean; isScheduledCall?: boolean; location?: string; name: string; quotedMsgId?: string; requireApproval?: boolean; startTime: number },
): Promise<string>
```

### Usage [!toc] [#sendevent-usage]

<InterfaceTabs>
  <InterfaceTab value="SDK">

```ts
const result = await client.sendEvent(
  "447123456789@c.us",
  {
    "name": "Community meetup",
    "startTime": 1893456000,
    "description": "Meet the community"
  },
);
```

  </InterfaceTab>
  <InterfaceTab value="SocketClient">

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.sendEvent({
  to: "447123456789@c.us",
  event: {
    "name": "Community meetup",
    "startTime": 1893456000,
    "description": "Meet the community"
  },
});
```

  </InterfaceTab>
  <InterfaceTab value="HTTP">

```bash
curl -X POST "http://localhost:8080/api/events/sendEvent" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data '{
    "to": "447123456789@c.us",
    "event": {
      "name": "Community meetup",
      "startTime": 1893456000,
      "description": "Meet the community"
    }
  }'
```

Response:

```json
{
  "success": true,
  "data": "example"
}
```

  </InterfaceTab>
</InterfaceTabs>

## `getEvents`

Page through a chat’s locally synced event history, newest first. Pass nextCursor as options.before to retrieve the next page.

```ts
client.getEvents(
  chatId: string,
  options?: { before?: string; limit?: number },
): Promise<EventPage>
```

### Usage [!toc] [#getevents-usage]

<InterfaceTabs>
  <InterfaceTab value="SDK">

```ts
const result = await client.getEvents("447123456789@c.us");
```

  </InterfaceTab>
  <InterfaceTab value="SocketClient">

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getEvents({
  chatId: "447123456789@c.us",
});
```

  </InterfaceTab>
  <InterfaceTab value="HTTP">

```bash
curl -G "http://localhost:8080/api/events/get" \
  -H "x-api-key: YOUR_API_KEY" \
  --data-urlencode "chatId=447123456789@c.us"
```

Response:

```json
{
  "success": true,
  "data": {
    "events": [],
    "nextCursor": "example"
  }
}
```
