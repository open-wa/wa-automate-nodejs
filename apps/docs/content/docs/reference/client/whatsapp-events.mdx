## `cancelEvent`

**Signature** `client.cancelEvent(eventId: string): Promise<boolean>`

### Usage

<InterfaceTabs>
  <InterfaceTab value="Embedded">

```ts

```

  </InterfaceTab>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');

  eventId: "false_447123456789@c.us_9C4D0965EA5C09D591334AB6BDB07FEB",
```

  </InterfaceTab>

```bash
  --data '{
    "eventId": "false_447123456789@c.us_9C4D0965EA5C09D591334AB6BDB07FEB"
  }'
```

```json

  "success": true,
```
