# Calendar events


## `sendEvent`

Send a native WhatsApp event with Unix-second times. Returns its submitted message ID; delivery is observed through ACKs.

<ReferenceCode>

```ts
client.sendEvent(to: string, event: EventInput): Promise<string>
```

</ReferenceCode>

<h3 id="sendevent-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SDK">

<ReferenceCode>

```ts
const result = await client.sendEvent(
  "447123456789@c.us",
  {
    "name": "Community meetup",
    "startTime": 1893456000,
    "description": "Meet the community"
  },
);
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.sendEvent({
  to: "447123456789@c.us",
  event: {
    "name": "Community meetup",
    "startTime": 1893456000,
    "description": "Meet the community"
  },
});
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
curl -X POST "http://localhost:8080/api/events/sendEvent" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data '{
    "to": "447123456789@c.us",
    "event": {
      "name": "Community meetup",
      "startTime": 1893456000,
      "description": "Meet the community"
    }
  }'
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": "example"
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="sendevent-parameters" className="scroll-m-28">Parameters</h3>

| Parameter | Type | Description |
| --- | --- | --- |
| `to` | `string` | Recipient chat ID. The target chat for a send operation. Also accepts `chatId`. |
| `event` | [`EventInput`](/docs/reference/client/return-types#eventinput) | - |

<h3 id="sendevent-returns" className="scroll-m-28">Returns</h3>

Resolves to `string`.

Message ID

The SDK resolves to `MessageId` instead.

**HTTP:** `POST /api/events/sendEvent`, or `/api/sendEvent`. **Also named:** `events.sendEvent`.


## `getEvents`

Page through a chat’s locally synced event history, newest first. Pass nextCursor as options.before to retrieve the next page.

<ReferenceCode>

```ts
client.getEvents(chatId: string, options?: EventListOptions): Promise<EventPage>
```

</ReferenceCode>

<h3 id="getevents-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SDK">

<ReferenceCode>

```ts
const result = await client.getEvents("447123456789@c.us");
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getEvents({
  chatId: "447123456789@c.us",
});
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
curl -G "http://localhost:8080/api/events/get" \
  -H "x-api-key: YOUR_API_KEY" \
  --data-urlencode "chatId=447123456789@c.us"
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": {
    "events": [],
    "nextCursor": "example"
  }
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="getevents-parameters" className="scroll-m-28">Parameters</h3>

| Parameter | Type | Description |
| --- | --- | --- |
| `chatId` | `string` | Recipient chat ID. The target chat for a send operation. Also accepts `chatId`. |
| `options` | [`EventListOptions`](/docs/reference/client/return-types#eventlistoptions) | Optional. |

<h3 id="getevents-returns" className="scroll-m-28">Returns</h3>

Resolves to [`EventPage`](/docs/reference/client/return-types#eventpage).

**HTTP:** `GET /api/events/get`, or `/api/getEvents`. **Also named:** `events.get`.
