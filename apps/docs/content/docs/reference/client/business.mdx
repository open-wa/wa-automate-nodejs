# Business


## `getBusinessProfile`

Get business profile

<ReferenceCode>

```ts
client.getBusinessProfile(contactId: string): Promise<BusinessProfile>
```

</ReferenceCode>

<h3 id="getbusinessprofile-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getBusinessProfile({
  contactId: "447123456789@c.us",
});
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
curl -G "http://localhost:8080/api/business/getProfile" \
  -H "x-api-key: YOUR_API_KEY" \
  --data-urlencode "contactId=447123456789@c.us"
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": {
    "id": "447123456789@c.us"
  }
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="getbusinessprofile-parameters" className="scroll-m-28">Parameters</h3>

| Parameter | Type | Description |
| --- | --- | --- |
| `contactId` | `string` | Contact ID. A WhatsApp contact JID. Also accepts `id`. |

<h3 id="getbusinessprofile-returns" className="scroll-m-28">Returns</h3>

Resolves to [`BusinessProfile`](/docs/reference/client/return-types#businessprofile).

The SDK `Client` doesn't have this method. Call it through SocketClient or HTTP.

**HTTP:** `GET /api/business/getProfile`, or `/api/getBusinessProfile`. **Also named:** `business.getProfile`.

## `getOrder`

Get order details

Needs an Insiders license. See [pricing](/docs/licensing/pricing).

<ReferenceCode>

```ts
client.getOrder(id: string): Promise<Order>
```

</ReferenceCode>

<h3 id="getorder-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getOrder({
  id: "id",
});
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
curl -G "http://localhost:8080/api/business/getOrder" \
  -H "x-api-key: YOUR_API_KEY" \
  --data-urlencode "id=id"
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": {
    "id": "example",
    "createdAt": 0,
    "currency": "example",
    "products": [],
    "sellerJid": "example",
    "subtotal": "example",
    "total": "example"
  }
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="getorder-parameters" className="scroll-m-28">Parameters</h3>

| Parameter | Type | Description |
| --- | --- | --- |
| `id` | `string` | Order or message ID. |

<h3 id="getorder-returns" className="scroll-m-28">Returns</h3>

Resolves to [`Order`](/docs/reference/client/return-types#order).

The SDK `Client` doesn't have this method. Call it through SocketClient or HTTP.

**HTTP:** `GET /api/business/getOrder`, or `/api/getOrder`. **Also named:** `business.getOrder`.
