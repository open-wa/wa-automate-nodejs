# Calls


## `getCallCapabilities`

Optional calling availability for UI and diagnostics. Actions perform admission automatically.

```ts
client.getCallCapabilities(): Promise<{ control: boolean; audio: boolean; video: boolean; reason?: { code: string; message: string; status: number | "Infinity" | "-Infinity" | "NaN" } }>
```

### Usage [!toc] [#getcallcapabilities-usage]

<InterfaceTabs>
  <InterfaceTab value="SDK">

```ts
const result = await client.getCallCapabilities();
```

  </InterfaceTab>
  <InterfaceTab value="SocketClient">

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getCallCapabilities();
```

  </InterfaceTab>
  <InterfaceTab value="HTTP">

```bash
curl -X POST "http://localhost:8080/api/calls/getCallCapabilities" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data '{}'
```

Response:

```json
{
  "success": true,
  "data": {
    "control": true,
    "audio": true,
    "video": true
  }
}
```

  </InterfaceTab>
</InterfaceTabs>
