# Calls


## `getCallCapabilities`

Optional calling availability for UI and diagnostics. Actions perform admission automatically.

<ReferenceCode>

```ts
client.getCallCapabilities(): Promise<{ … }>
```

</ReferenceCode>

<h3 id="getcallcapabilities-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SDK">

<ReferenceCode>

```ts
const result = await client.getCallCapabilities();
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getCallCapabilities();
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
curl -X POST "http://localhost:8080/api/calls/getCallCapabilities" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data '{}'
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": {
    "control": true,
    "audio": true,
    "video": true
  }
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="getcallcapabilities-parameters" className="scroll-m-28">Parameters</h3>

This method takes no parameters.

<h3 id="getcallcapabilities-returns" className="scroll-m-28">Returns</h3>

Resolves to:

<ReferenceCode>

```ts
{ control: boolean; audio: boolean; video: boolean; reason?: { code: string; message: string; status: number | "Infinity" | "-Infinity" | "NaN" } }
```

</ReferenceCode>

The SDK resolves to `CallCapabilities` instead.

**HTTP:** `POST /api/calls/getCallCapabilities`, or `/api/getCallCapabilities`. **Also named:** `calls.getCallCapabilities`.
