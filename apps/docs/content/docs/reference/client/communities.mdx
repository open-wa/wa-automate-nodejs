## `getAllCommunities`

Get all communities

Needs an Insiders license. See [pricing](/docs/licensing/pricing).

<ReferenceCode>

```ts
client.getAllCommunities(): Promise<GroupChatId[]>
```

</ReferenceCode>

<h3 id="getallcommunities-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SDK">

<ReferenceCode>

```ts
const result = await client.getAllCommunities();
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getAllCommunities();
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
curl -X GET "http://localhost:8080/api/communities/getAll" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data '{}'
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": []
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="getallcommunities-parameters" className="scroll-m-28">Parameters</h3>

This method takes no parameters.

<h3 id="getallcommunities-returns" className="scroll-m-28">Returns</h3>

Resolves to `GroupChatId[]`. See [GroupChatId](/docs/reference/client/return-types#groupchatid) for its fields.

Opaque group conversation identifier returned by a group lookup or join method.

**HTTP:** `GET /api/communities/getAll`, or `/api/communities/all`, `/api/communities/list`, `/api/getAllCommunities`, `/api/listCommunities`. **Also named:** `communities.all`, `communities.getAll`, `communities.list`, `listCommunities`.

</LicensedMethodSection>

## `getCommunityInfo`

Get community metadata

Needs an Insiders license. See [pricing](/docs/licensing/pricing).

<ReferenceCode>

```ts
client.getCommunityInfo(communityId: string): Promise<CommunityMetadata>
```

</ReferenceCode>

<h3 id="getcommunityinfo-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SDK">

<ReferenceCode>

```ts
const result = await client.getCommunityInfo("447123456789-1445627445@g.us");
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getCommunityInfo({
  communityId: "447123456789-1445627445@g.us",
});
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
curl -G "http://localhost:8080/api/communities/getInfo" \
  -H "x-api-key: YOUR_API_KEY" \
  --data-urlencode "communityId=447123456789-1445627445@g.us"
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": {
    "id": "447123456789-1445627445@g.us",
    "subject": "example",
    "creation": 0,
    "participants": [],
    "subGroups": []
  }
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="getcommunityinfo-parameters" className="scroll-m-28">Parameters</h3>

| Parameter | Type | Description |
| --- | --- | --- |
| `communityId` | `string` | Community ID. A WhatsApp community JID. |

<h3 id="getcommunityinfo-returns" className="scroll-m-28">Returns</h3>

Resolves to [`CommunityMetadata`](/docs/reference/client/return-types#communitymetadata).

**HTTP:** `GET /api/communities/getInfo`, or `/api/getCommunityInfo`. **Also named:** `communities.getInfo`.

</LicensedMethodSection>
