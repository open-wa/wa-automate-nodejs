# Chat IDs


## `getAllChatIds`

Get all chat IDs

<ReferenceCode>

```ts
client.getAllChatIds(): Promise<ChatId[]>
```

</ReferenceCode>

<h3 id="getallchatids-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getAllChatIds();
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
curl -X GET "http://localhost:8080/api/chatIds/getAll" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data '{}'
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": []
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="getallchatids-parameters" className="scroll-m-28">Parameters</h3>

This method takes no parameters.

<h3 id="getallchatids-returns" className="scroll-m-28">Returns</h3>

Resolves to `ChatId[]`. See [ChatId](/docs/reference/client/return-types#chatid) for its fields.

Opaque conversation identifier. Use the exact value returned by a message event or chat lookup.

The SDK `Client` doesn't have this method. Call it through SocketClient or HTTP.

**HTTP:** `GET /api/chatIds/getAll`, or `/api/chatIds/all`, `/api/chatIds/list`, `/api/chats/ids`, `/api/getAllChatIds`, `/api/listChatIds`. **Also named:** `chatIds.all`, `chatIds.getAll`, `chatIds.list`, `chats.ids`, `listChatIds`.
