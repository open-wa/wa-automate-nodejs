# Chats


## `getAllChats`

Returns serialized Chat objects from the current session, optionally limited to chats with unread messages.

<ReferenceCode>

```ts
client.getAllChats(withNewMessagesOnly?: boolean): Promise<Chat[]>
```

</ReferenceCode>

<h3 id="getallchats-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SDK">

<ReferenceCode>

```ts
const result = await client.getAllChats();
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getAllChats();
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
curl -X GET "http://localhost:8080/api/chats/getAll" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data '{}'
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": []
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="getallchats-parameters" className="scroll-m-28">Parameters</h3>

| Parameter | Type | Description |
| --- | --- | --- |
| `withNewMessagesOnly` | `boolean` | Optional. Only chats with unread messages. |

<h3 id="getallchats-returns" className="scroll-m-28">Returns</h3>

Resolves to `Chat[]`. See [Chat](/docs/reference/client/return-types#chat) for its fields.

Serialized chat returned by chat lookups and listings. Its id is an opaque ChatId; additional WhatsApp Web fields may be present.

**HTTP:** `GET /api/chats/getAll`, or `/api/chats/all`, `/api/chats/list`, `/api/getAllChats`, `/api/listChats`. **Also named:** `chats.all`, `chats.getAll`, `chats.list`, `listChats`.


## `getChat`

Get specific chat by ID

<ReferenceCode>

```ts
client.getChat(chatId: string): Promise<Chat | null | undefined | false>
```

</ReferenceCode>

<h3 id="getchat-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SDK">

<ReferenceCode>

```ts
const result = await client.getChat("447123456789@c.us");
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getChat({
  chatId: "447123456789@c.us",
});
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
curl -G "http://localhost:8080/api/chats/get" \
  -H "x-api-key: YOUR_API_KEY" \
  --data-urlencode "chatId=447123456789@c.us"
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": {
    "id": "447123456789@c.us",
    "isGroup": true,
    "contact": {
      "id": "447123456789@c.us"
    }
  }
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="getchat-parameters" className="scroll-m-28">Parameters</h3>

| Parameter | Type | Description |
| --- | --- | --- |
| `chatId` | `string` | Chat ID (phone number or formatted ID) A contact ID, group ID, or LID JID. Also accepts `contactId`, `id`. |

<h3 id="getchat-returns" className="scroll-m-28">Returns</h3>

Resolves to `Chat | null | undefined | false`. See [Chat](/docs/reference/client/return-types#chat) for its fields.

The SDK resolves to `Chat | false | undefined` instead.

**HTTP:** `GET /api/chats/get`, or `/api/chats/getById`, `/api/getChat`, `/api/getChatById`. **Also named:** `chats.get`, `chats.getById`, `getChatById`.
