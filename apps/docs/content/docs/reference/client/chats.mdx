# Chats


## `getAllChats`

Returns serialized Chat objects from the current session, optionally limited to chats with unread messages.

```ts
client.getAllChats(withNewMessagesOnly?: boolean): Promise<Chat[]>
```

### Usage [!toc] [#getallchats-usage]

<InterfaceTabs>
  <InterfaceTab value="SDK">

```ts
const result = await client.getAllChats();
```

  </InterfaceTab>
  <InterfaceTab value="SocketClient">

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getAllChats();
```

  </InterfaceTab>
  <InterfaceTab value="HTTP">

```bash
curl -X GET "http://localhost:8080/api/chats/getAll" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data '{}'
```

Response:

```json
{
  "success": true,
  "data": []
}
```

  </InterfaceTab>
</InterfaceTabs>

### Parameters [!toc] [#getallchats-parameters]

<AutoTypeTable path="./generated-method-params.ts" name="GetAllChatsParams" />

### Returns [!toc] [#getallchats-returns]

Resolves to `Chat[]`. See [Chat](/docs/reference/client/return-types#chat) for its fields.

Serialized chat returned by chat lookups and listings. Its id is an opaque ChatId; additional WhatsApp Web fields may be present.

```ts
  chatId: "447123456789@c.us",
});
```

  </InterfaceTab>
  <InterfaceTab value="HTTP">

```bash

  -H "x-api-key: YOUR_API_KEY" \
```


```ts
client.setChatEphemeral(chatId: string, ephemeral: boolean | number): Promise<boolean>
```

### Usage [!toc] [#setchatephemeral-usage]

<InterfaceTabs>
  <InterfaceTab value="SocketClient">

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.setChatEphemeral({
  chatId: "447123456789@c.us",
  ephemeral: 1,
});
```

  </InterfaceTab>
  <InterfaceTab value="HTTP">

```bash
curl -X PUT "http://localhost:8080/api/chats/setEphemeral" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data '{
    "chatId": "447123456789@c.us",
    "ephemeral": 1
  }'
```

Response:

```json
{
  "success": true,
  "data": true
}
```

  </InterfaceTab>
</InterfaceTabs>
