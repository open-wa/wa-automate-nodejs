## `createGroup`

Create new group

Needs a Restricted license. See [pricing](/docs/licensing/pricing).

<ReferenceCode>

```ts
client.createGroup(name: string, contacts: string[]): Promise<GroupCreationResult | null>
```

</ReferenceCode>

<h3 id="creategroup-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SDK">

<ReferenceCode>

```ts
const result = await client.createGroup("name", ["447123456789@c.us"]);
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.createGroup({
  name: "name",
  contacts: ["447123456789@c.us"],
});
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
curl -X POST "http://localhost:8080/api/groups/create" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data '{
    "name": "name",
    "contacts": [
      "447123456789@c.us"
    ]
  }'
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": {
    "gid": "447123456789-1445627445@g.us"
  }
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="creategroup-parameters" className="scroll-m-28">Parameters</h3>

| Parameter | Type | Description |
| --- | --- | --- |
| `name` | `string` | Group name. |
| `contacts` | `string[]` | Contact IDs to add. A WhatsApp contact JID. Also accepts `id`. |

<h3 id="creategroup-returns" className="scroll-m-28">Returns</h3>

Resolves to `GroupCreationResult | null`. See [GroupCreationResult](/docs/reference/client/return-types#groupcreationresult) for its fields.

The SDK resolves to `{ gid: GroupId } | null` instead.

**HTTP:** `POST /api/groups/create`, or `/api/createGroup`. **Also named:** `groups.create`.

</LicensedMethodSection>
