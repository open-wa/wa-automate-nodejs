# Contact status

<LicensedMethodSection tier="insiders">

<span id="getstatus---insiders" aria-hidden="true"></span>
## `getStatus`

Get specific status

Needs an Insiders license. See [pricing](/docs/licensing/pricing).

<ReferenceCode>

```ts
client.getStatus(contactId: string): Promise<ContactStatus>
```

</ReferenceCode>

<h3 id="getstatus-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getStatus({
  contactId: "447123456789@c.us",
});
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
curl -G "http://localhost:8080/api/mystatus/getStatus" \
  -H "x-api-key: YOUR_API_KEY" \
  --data-urlencode "contactId=447123456789@c.us"
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": {
    "id": "example",
    "status": "example"
  }
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="getstatus-parameters" className="scroll-m-28">Parameters</h3>

| Parameter | Type | Description |
| --- | --- | --- |
| `contactId` | `string` | Contact ID. A WhatsApp contact JID. Also accepts `id`. |

<h3 id="getstatus-returns" className="scroll-m-28">Returns</h3>

Resolves to [`ContactStatus`](/docs/reference/client/return-types#contactstatus).

The SDK `Client` doesn't have this method. Call it through SocketClient or HTTP.

**HTTP:** `GET /api/mystatus/getStatus`, or `/api/getStatus`. **Also named:** `mystatus.getStatus`.
