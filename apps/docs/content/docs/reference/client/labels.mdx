# Labels


## `getAllLabels`

Get all labels

```ts
client.getAllLabels(): Promise<Label[]>
```

### Usage [!toc] [#getalllabels-usage]

<InterfaceTabs>
  <InterfaceTab value="SocketClient">

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getAllLabels();
```

  </InterfaceTab>
  <InterfaceTab value="HTTP">

```bash
curl -X GET "http://localhost:8080/api/labels/getAll" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data '{}'
```

Response:

```json
{
  "success": true,
  "data": []
}
```

  </InterfaceTab>
</InterfaceTabs>

This method does not define input parameters.

## `getChatsByLabel`

Get chats by label

```ts
client.getChatsByLabel(label: string): Promise<Chat[]>
```

### Usage [!toc] [#getchatsbylabel-usage]

<InterfaceTabs>
  <InterfaceTab value="SocketClient">

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getChatsByLabel({
  label: "label",
});
```

  </InterfaceTab>
  <InterfaceTab value="HTTP">

```bash
curl -G "http://localhost:8080/api/labels/getChats" \
  -H "x-api-key: YOUR_API_KEY" \
  --data-urlencode "label=label"
```

Response:

```json
{
  "success": true,
  "data": []
}
```

  </InterfaceTab>
</InterfaceTabs>

### Parameters [!toc] [#getchatsbylabel-parameters]

<AutoTypeTable path="./generated-method-params.ts" name="GetChatsByLabelParams" />

Resolves to `Chat[]`. See [Chat](/docs/reference/client/return-types#chat) for its fields.

Serialized chat returned by chat lookups and listings. Its id is an opaque ChatId; additional WhatsApp Web fields may be present.
