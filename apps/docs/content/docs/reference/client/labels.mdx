# Labels


## `getAllLabels`

Get all labels

<ReferenceCode>

```ts
client.getAllLabels(): Promise<Label[]>
```

</ReferenceCode>

<h3 id="getalllabels-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getAllLabels();
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
curl -X GET "http://localhost:8080/api/labels/getAll" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data '{}'
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": []
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="getalllabels-parameters" className="scroll-m-28">Parameters</h3>

This method takes no parameters.

<h3 id="getalllabels-returns" className="scroll-m-28">Returns</h3>

Resolves to `Label[]`. See [Label](/docs/reference/client/return-types#label) for its fields.

The SDK `Client` doesn't have this method. Call it through SocketClient or HTTP.

**HTTP:** `GET /api/labels/getAll`, or `/api/getAllLabels`, `/api/labels/all`, `/api/labels/list`, `/api/listLabels`. **Also named:** `labels.all`, `labels.getAll`, `labels.list`, `listLabels`.


## `addLabel`

Add label to chat

<ReferenceCode>

```ts
client.addLabel(label: string, chatId: string): Promise<boolean>
```

</ReferenceCode>

<h3 id="addlabel-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.addLabel({
  label: "label",
  chatId: "447123456789@c.us",
});
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
curl -X PUT "http://localhost:8080/api/labels/add" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data '{
    "label": "label",
    "chatId": "447123456789@c.us"
  }'
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": true
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="addlabel-parameters" className="scroll-m-28">Parameters</h3>

| Parameter | Type | Description |
| --- | --- | --- |
| `label` | `string` | Label ID or name. |
| `chatId` | `string` | Recipient chat ID. The target chat for a send operation. Also accepts `chatId`. |

<h3 id="addlabel-returns" className="scroll-m-28">Returns</h3>

Resolves to `boolean`.

The SDK `Client` doesn't have this method. Call it through SocketClient or HTTP.

**HTTP:** `PUT /api/labels/add`, or `/api/addLabel`. **Also named:** `labels.add`.

## `getChatsByLabel`

Get chats by label

<ReferenceCode>

```ts
client.getChatsByLabel(label: string): Promise<Chat[]>
```

</ReferenceCode>

<h3 id="getchatsbylabel-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getChatsByLabel({
  label: "label",
});
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
curl -G "http://localhost:8080/api/labels/getChats" \
  -H "x-api-key: YOUR_API_KEY" \
  --data-urlencode "label=label"
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": []
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="getchatsbylabel-parameters" className="scroll-m-28">Parameters</h3>

| Parameter | Type | Description |
| --- | --- | --- |
| `label` | `string` | Label name. |

<h3 id="getchatsbylabel-returns" className="scroll-m-28">Returns</h3>

Resolves to `Chat[]`. See [Chat](/docs/reference/client/return-types#chat) for its fields.

Serialized chat returned by chat lookups and listings. Its id is an opaque ChatId; additional WhatsApp Web fields may be present.

The SDK `Client` doesn't have this method. Call it through SocketClient or HTTP.

**HTTP:** `GET /api/labels/getChats`, or `/api/getChatsByLabel`, `/api/labels/getChatsBy`. **Also named:** `labels.getChats`, `labels.getChatsBy`.
