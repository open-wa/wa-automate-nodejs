# Media methods


## `decryptMedia`

Decrypts media from a message

<ReferenceCode>

```ts
client.decryptMedia(message: Message): Promise<DataURL>
```

</ReferenceCode>

<h3 id="decryptmedia-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SDK">

<ReferenceCode>

```ts
// Use the full media message from your message handler.
const result = await client.decryptMedia(message);
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
// Use the full media message received by your message handler.
const result = await client.decryptMedia({ message });
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
# Save the full incoming media message as the "message" field in request.json.
# For downloadMedia, also set "path" to the destination filename.
curl -X POST "http://localhost:8080/api/media/decrypt" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data-binary @request.json
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": "data:image/png;base64,..."
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="decryptmedia-parameters" className="scroll-m-28">Parameters</h3>

| Parameter | Type | Description |
| --- | --- | --- |
| `message` | [`Message`](/docs/reference/client/return-types#message) | Message object containing media. |

<h3 id="decryptmedia-returns" className="scroll-m-28">Returns</h3>

Resolves to [`DataURL`](/docs/reference/client/return-types#dataurl).

**HTTP:** `POST /api/media/decrypt`, or `/api/decryptMedia`. **Also named:** `media.decrypt`.


## `downloadMedia`

Downloads and decrypts media from a message to a file

<ReferenceCode>

```ts
client.downloadMedia(message: Message, path: string): Promise<string>
```

</ReferenceCode>

<h3 id="downloadmedia-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SDK">

<ReferenceCode>

```ts
// Use the full media message from your message handler.
const result = await client.downloadMedia(message, "./downloaded-media");
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
// Use the full media message received by your message handler.
const result = await client.downloadMedia({ message, path: "./downloaded-media" });
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
# Save the full incoming media message as the "message" field in request.json.
# For downloadMedia, also set "path" to the destination filename.
curl -X POST "http://localhost:8080/api/media/download" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data-binary @request.json
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": "example"
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="downloadmedia-parameters" className="scroll-m-28">Parameters</h3>

| Parameter | Type | Description |
| --- | --- | --- |
| `message` | [`Message`](/docs/reference/client/return-types#message) | Message object containing media. |
| `path` | `string` | File path to save the media. |

<h3 id="downloadmedia-returns" className="scroll-m-28">Returns</h3>

Resolves to `string`.

Path to the saved file

**HTTP:** `POST /api/media/download`, or `/api/downloadMedia`. **Also named:** `media.download`.
