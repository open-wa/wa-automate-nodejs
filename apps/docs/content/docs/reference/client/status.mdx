<LicensedMethodSection tier="insiders">

## `postTextStatus`

Post text status

Needs an Insiders license. See [pricing](/docs/licensing/pricing).

<ReferenceCode>

```ts
client.postTextStatus(
  text: string,
  backgroundColor?: string,
  font?: number,
): Promise<MessageId | string | boolean>
```

</ReferenceCode>

<h3 id="posttextstatus-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SDK">

<ReferenceCode>

```ts
const result = await client.postTextStatus("text");
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.postTextStatus({
  text: "text",
});
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
curl -X POST "http://localhost:8080/api/status/postText" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data '{
    "text": "text"
  }'
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": "true_447123456789@c.us_9C4D0965EA5C09D591334AB6BDB07FEB"
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="posttextstatus-parameters" className="scroll-m-28">Parameters</h3>

| Parameter | Type | Description |
| --- | --- | --- |
| `text` | `string` | Status text. |
| `backgroundColor` | `string` | Optional. Background color. |
| `font` | `number` | Optional. Font style. |

<h3 id="posttextstatus-returns" className="scroll-m-28">Returns</h3>

Resolves to `MessageId | string | boolean`. See [MessageId](/docs/reference/client/return-types#messageid) for its fields.

The SDK resolves to `MediaSendResult` instead.

**HTTP:** `POST /api/status/postText`, or `/api/postTextStatus`. **Also named:** `status.postText`.

</LicensedMethodSection>

## `getStories`

Get all stories

Needs an Insiders license. See [pricing](/docs/licensing/pricing).

<ReferenceCode>

```ts
client.getStories(): Promise<Story[]>
```

</ReferenceCode>

<h3 id="getstories-usage" className="scroll-m-28">Usage</h3>

<InterfaceTabs>
  <InterfaceTab value="SocketClient">

<ReferenceCode>

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.getStories();
```

</ReferenceCode>

  </InterfaceTab>
  <InterfaceTab value="HTTP">

<ReferenceCode>

```bash
curl -X GET "http://localhost:8080/api/status/getAll" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data '{}'
```

</ReferenceCode>

Response:

<ReferenceCode>

```json
{
  "success": true,
  "data": []
}
```

</ReferenceCode>

  </InterfaceTab>
</InterfaceTabs>

<h3 id="getstories-parameters" className="scroll-m-28">Parameters</h3>

This method takes no parameters.

<h3 id="getstories-returns" className="scroll-m-28">Returns</h3>

Resolves to `Story[]`. See [Story](/docs/reference/client/return-types#story) for its fields.

Message-shaped status entry, based on the legacy story API. Chat and sender may be absent or null. The licensed getStories payload has not been verified against this model.

The SDK `Client` doesn't have this method. Call it through SocketClient or HTTP.

**HTTP:** `GET /api/status/getAll`, or `/api/getStatuses`, `/api/getStories`, `/api/status/get`, `/api/status/getStories`. **Also named:** `getStatuses`, `status.get`, `status.getAll`, `status.getStories`.

</LicensedMethodSection>
