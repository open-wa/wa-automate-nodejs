## `postTextStatus`

Post text status

Needs an Insiders license. See [pricing](/docs/licensing/pricing).

```ts
client.postTextStatus(
  text: string,
  backgroundColor?: string,
  font?: number,
): Promise<MessageId | string | boolean>
```

### Usage [!toc] [#posttextstatus-usage]

<InterfaceTabs>
  <InterfaceTab value="SDK">

```ts
const result = await client.postTextStatus("text");
```

  </InterfaceTab>
  <InterfaceTab value="SocketClient">

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
const result = await client.postTextStatus({
  text: "text",
});
```

  </InterfaceTab>
  <InterfaceTab value="HTTP">

```bash
curl -X POST "http://localhost:8080/api/status/postText" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  --data '{
    "text": "text"
  }'
```

Response:

```json
{
  "success": true,
  "data": "true_447123456789@c.us_9C4D0965EA5C09D591334AB6BDB07FEB"
}
```

  </InterfaceTab>
</InterfaceTabs>
