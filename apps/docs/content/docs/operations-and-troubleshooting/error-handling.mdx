# Error handling

Treat every client method as an async operation and handle failures explicitly.

<Callout type="warning" title="Do not treat runtime failures as one category">
  In practice you are usually dealing with one of three different failure
  classes: application-level method failures, create/launch failures, or
  browser/runtime failures. Handle them differently.
</Callout>

## Application-level pattern

```ts
client.onMessage(async (message) => {
  try {
    await client.sendText(message.from, 'Hi!');
  } catch (error) {
    console.error(error);
  }
});
```

## Handling `create()` failures

```ts
async function launch() {
  try {
    const client = await create();
    await start(client);
  } catch (error) {
    console.error(error);
  }
}
```
