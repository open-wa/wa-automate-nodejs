# Pricing

open-wa is free to run. A license is only needed for the [licensed features](/docs/licensing/licensed-features): starting chats with new numbers, stories and status, the Insiders methods such as `checkNumberStatus` and `getNumberProfile`, interactive messages such as buttons, lists and booking cards, and the audio calling preview. One license covers one WhatsApp number and unlocks all of them.

Prices are per license, per month, in GBP and before tax. Each band's price applies to the licenses inside that band, so your first five licenses always cost the first band's price. If you commit to at least a band's starting quantity, every license is charged at that band's price instead.

## How a key binds to a number

Each license is assigned to one WhatsApp number, the one you enter when you buy it. When a session starts with a key, open-wa checks the key against the number that session is logged in as, and the licensed features only unlock on that number. Pass the key as `licenseKey` to `create()`, as `--license-key` or `WA_LICENSE_KEY` for the Easy API, or apply it from the dashboard's license badge without restarting. To move a license to another number, change the number in your account on openwa.cloud: the first change is available straight away, and later changes once every 30 days.

## If a key doesn't work

The session still starts and every unlicensed method keeps working, so a key problem never takes your bot offline. Read the `license` object from `/health`, or call `client.getLicenseFeatures()` in the SDK, and check its `status`. `invalid` means the key was rejected, usually because the session is logged in as a different number from the one the license is assigned to, or the subscription has ended; `missing` means no key reached the session. Fix the number or the subscription, then apply the key again from the dashboard or restart the session. If it still fails, ask on [Discord](https://discord.gg/dnpp72a) with the `license` object from `/health`, with the key and number masked.
