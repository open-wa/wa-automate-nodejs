# Pricing

You can run open-wa for free. Connect your WhatsApp account, read chats and send messages to existing chats with the [free quickstart](/docs/getting-started/quickstart).

<GetLicenseButton className="not-prose my-2" label="See license options" />

## Paid license options

The license form lists **Insiders** and **Restricted** feature keys. Each license key is assigned to one WhatsApp number.

| What you want to do | Runtime requirement |
| --- | --- |
| Read chats or send ordinary messages to existing chats | No license required |
| Look up a number or profile with `checkNumberStatus` or `getNumberProfile` | Insiders feature |
| Create a group with `createGroup` or join with `joinGroupViaLink` | Restricted feature |

These are examples of runtime requirements. Check the current offer for the features included in your purchase.

## How a key binds to a number

Each license is assigned to one WhatsApp number, the one you enter when you buy it. When a session starts with a key, open-wa checks the key against the number that session is logged in as, and the licensed features only unlock on that number. Pass the key as `licenseKey` to `create()`, as `--license-key` or `WA_LICENSE_KEY` for the Easy API, or apply it from the dashboard's license badge without restarting. To move a license to another number, open the license manager in your [open-wa account](https://app.openwa.cloud/dashboard?view=licenses) and review the available options.

## If a key doesn't work

The session still starts and every unlicensed method keeps working, so a key problem never takes your bot offline. Read the `license` object from `/health`, or call `client.getLicenseFeatures()` in the SDK, and check its `status`. `invalid` means the key was rejected, usually because the session is logged in as a different number from the one the license is assigned to, or the subscription has ended; `missing` means no key reached the session. Fix the number or the subscription, then apply the key again from the dashboard or restart the session. If it still fails, ask on [Discord](https://discord.gg/dnpp72a) with the `license` object from `/health`, with the key and number masked.
