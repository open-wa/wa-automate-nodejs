# Socket Client

`SocketClient` is the compatibility client for connecting to a remote Easy API instance. In the current runtime it uses **HTTP RPC for commands** and **Server-Sent Events for runtime events**, while keeping a client-style surface for consumers.

<Callout type="tip" title="Best fit for SocketClient">
  Use SocketClient when the session already lives elsewhere and your app only
  needs to issue commands, receive events, and stay light on browser/runtime
  responsibilities.
</Callout>

<Steps>
  <Step title="Connect to a running Easy API session">

## Connect to a local or remote Easy API

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'your-api-key');
```

The client surface exposes direct methods such as `sendText(...)`, and you can also use `ask(...)` / `listen(...)` when you want the explicit transport-level style.

  </Step>
  <Step title="Authenticate the consumer">

## Authentication

If your Easy API instance is protected with an API key, pass it when connecting:

```ts
const client = await SocketClient.connect('https://api.example.com', 'your-api-key');
```

Keep the API key out of browser-exposed code unless that browser is a trusted internal client.

  </Step>
  <Step title="Use commands and events like a client surface">

## Send a command

```ts
await client.sendText('1234567890@c.us', 'Hello from SocketClient');

// explicit RPC style also works
await client.ask('sendText', {
  to: '1234567890@c.us',
  content: 'Hello from SocketClient',
});
```

## Listen to events

```ts
client.onMessage((message) => {
  console.log(message.body);
});

await client.listen('onMessage', (message) => {
  console.log(message.body);
});
```

Legacy-style listener helpers are mapped onto the active runtime event stream for you, so you can usually keep familiar event names.

  </Step>
  <Step title="Choose the right transport edge">

## Cloudflare proxy URLs

`SocketClient.connect()` also understands `cf-proxy://...` URLs for the Cloudflare tunnel flow described in **[Cloudflare Session Proxy](/docs/client-and-integrations/cf-proxy)**.

If you need the concrete delivery envelope shapes for downstream consumers, read
**[Webhook payloads](/docs/client-and-integrations/webhook-payloads)**.

  </Step>
</Steps>

## When to use it

Use `SocketClient` when:

- your automation runtime lives on another machine
- you want a lightweight consumer app instead of embedding the full browser automation runtime
- you want to connect dashboards, workers, or services to an Easy API instance
