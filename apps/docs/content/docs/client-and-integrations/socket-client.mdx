# SocketClient

`SocketClient` is the remote client library for communicating with a running Easy API daemon. It uses **HTTP RPC for method invocation** and **Server-Sent Events (SSE) for real-time events**, providing an idiomatic client interface without requiring a local Chromium browser process.

## Installation

Install the package in your application workspace:

<PackageManagerTabs command="install @open-wa/socket-client" />

## Connect to Easy API

Initialize the client with the Easy API base URL and optional API key:

```ts
import { SocketClient } from '@open-wa/socket-client';

const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');
```

The returned client exposes standard automation methods such as `sendText()`, as well as transport primitives like `ask()` and `listen()`.

## Authentication

When Easy API requires authentication, provide the secret key as the second parameter:

```ts
const client = await SocketClient.connect('https://api.example.com', 'YOUR_API_KEY');
```

For HTTP RPC requests, `SocketClient` attaches the `X-API-Key: YOUR_API_KEY` header. For the SSE event connection, the client includes `?api_key=YOUR_API_KEY` in the query parameters.

## Complete consumer example

```ts
import { SocketClient, type Client } from '@open-wa/socket-client';

const EASY_API_URL = process.env.OPENWA_API_URL ?? 'http://localhost:8080';
const API_KEY = process.env.OPENWA_API_KEY ?? 'YOUR_API_KEY';
const TEST_CHAT_ID = process.env.OPENWA_TEST_CHAT_ID ?? '447700900000@c.us';

async function main() {
  const client = (await SocketClient.connect(EASY_API_URL, API_KEY)) as SocketClient & Client;

  client.socket.on('connect', () => {
    console.log('Connected to Easy API event stream');
  });

  client.socket.on('disconnect', (reason) => {
    console.warn('Easy API event stream disconnected:', reason);
  });

  client.socket.on('connect_error', (error) => {
    console.error('Could not connect to Easy API events:', error);
  });

  await client.listen('onMessage', async (message) => {
    try {
      console.log('Incoming message:', message.from, message.body);

      if (message.body?.toLowerCase() === 'ping') {
        await client.sendText(message.from, 'pong');
      }
    } catch (error) {
      console.error('Failed to handle incoming message:', error);
    }
  });

  try {
    const sent = await client.sendText(TEST_CHAT_ID, 'SocketClient consumer is online');
    console.log('Startup message sent:', sent);
  } catch (error) {
    console.error('Failed to send startup message:', error);
  }

  process.once('SIGINT', () => {
    client.close();
    process.exit(0);
  });
}

main().catch((error) => {
  console.error('SocketClient consumer failed to start:', error);
  process.exit(1);
});
```

Run the consumer script:

```bash
OPENWA_API_URL="http://localhost:8080" \
OPENWA_API_KEY="YOUR_API_KEY" \
OPENWA_TEST_CHAT_ID="447700900000@c.us" \
npx tsx consumer.ts
```

## Send commands

Invoke methods directly or use the generic `ask()` RPC helper:

```ts
// Direct method invocation
await client.sendText('447700900000@c.us', 'Hello from SocketClient');

// Generic RPC invocation
await client.ask('sendText', {
  to: '447700900000@c.us',
  content: 'Hello from SocketClient',
});
```

## Subscribe to events

Subscribe to events using listener methods or the `listen()` helper:

```ts
client.onMessage((message) => {
  console.log('Received message:', message.body);
});

await client.listen('onMessage', (message) => {
  console.log('Received message:', message.body);
});
```

## Lifecycle and automatic reconnection

`SocketClient.connect()` resolves once the SSE event stream establishes an active connection.

Monitor connection state using the underlying socket emitter:

```ts
client.socket.on('connect', () => {
  console.log('Event stream connected');
});

client.socket.on('disconnect', (reason) => {
  console.log('Event stream disconnected:', reason);
});

client.socket.on('connect_error', (error) => {
  console.error('Event stream connection error:', error);
});
```

The client automatically attempts reconnection when the SSE stream drops. Event subscriptions are preserved and re-registered upon reconnect. To force reconnection manually, invoke:

```ts
await client.reconnect();
```

To terminate the client and close active connections, call `client.close()` or `client.disconnect()`.

## Handle connection errors

If the initial connection attempt fails, `SocketClient.connect()` rejects with an error:

```ts
try {
  const client = await SocketClient.connect('http://localhost:8080', 'YOUR_API_KEY');

  client.socket.on('disconnect', async () => {
    try {
      await client.reconnect();
    } catch (error) {
      console.error('Manual reconnect failed:', error);
    }
  });
} catch (error) {
  console.error('Failed to connect to Easy API:', error);
}
```

## Connect via Cloudflare session proxy

`SocketClient.connect()` natively accepts `cf-proxy://` URLs for sessions routed through Cloudflare Tunnels:

```ts
const client = await SocketClient.connect('cf-proxy://YOUR_TUNNEL_DOMAIN', 'YOUR_API_KEY');
```

For setup instructions, see [Cloudflare session proxy](/docs/client-and-integrations/cf-proxy).

## When to use SocketClient

- **Distributed architectures**: Run the browser runtime on dedicated infrastructure while deploying lightweight business logic across serverless or container clusters.
- **Resource conservation**: Eliminate browser memory overhead in secondary microservices.
- **Multi-service integrations**: Allow multiple backend services to share a single WhatsApp connection.

## Security considerations

`SocketClient` communicates with Easy API over network endpoints. Ensure that:

- All external network traffic routes through HTTPS.
- You supply strong API keys in production.
- Client credentials and API keys remain strictly in server-side configuration.

## Troubleshooting

- Ensure the base URL includes the protocol (`http://` or `https://`) and port.
- Confirm the Easy API server has finished WhatsApp Web authentication and reports `ready` before calling automation methods.
- If receiving 401 Unauthorized errors, verify that `apiKey` matches the configuration on the Easy API server.
