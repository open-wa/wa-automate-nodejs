# 🔒️ OpenWA 5.4.0 — your session, your key

Your compact session can travel with an encryption key you control!

## ✨ What's new

- 🔒️ **Bring your own key.** Set `sessionDataEncryptionKey`, use `OPENWA_SESSION_DATA_ENCRYPTION_KEY`, or mount a secret with `sessionDataEncryptionKeyFile`. Omit these to use the baked default.
- 🚚 **Built-in compact auth.** One encrypted `{ auth, data }` file, with existing filenames and S3 settings. `legacyDataDirAuth` is removed.
- 🩹 **Keep secrets out of diagnostics.** Key settings are redacted from debug responses and startup events; verbose environment logs show names only.

## 🚚 Upgrading

Use a base64-encoded 32-byte key and keep it with the same session ID across containers. Moving from a browser profile or changing keys requires a fresh QR scan. To reset a saved session, launch once with `sessionData: 'NUKE'`, then remove it.

Live browser/S3 acceptance for this integration remains unverified.
