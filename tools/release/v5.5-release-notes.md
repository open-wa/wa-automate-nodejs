## Events, live refresh and local stickers

OpenWA 5.5 adds native event cards and RSVPs, refresh controls for running sessions, and a local sticker package that avoids a Sharp installation.

- ✨ Create, edit and cancel events, read synced invitations and attendance, and subscribe to event changes and decrypted RSVPs. Event times use Unix seconds.
- 🔄 Refresh public patches or apply a licence from the dashboard without restarting the Node process. WhatsApp reloads during refresh, so messages may be missed while the page is unavailable.
- 🎨 Create WebP stickers with ordered effects through `@open-wa/stickers` or `openwa-sticker`. Jobs use the existing browser when it can complete them, otherwise the whole job runs standalone. Resources load on demand.
- ✨ Add typed media options, poll voting/results/listeners, message pins and voluntary phone-number requests. Captions and quoted IDs now belong in the media options object.
- 🐛 Restore patch-backed sending, message edits, reactions, group contacts and participant listeners; preserve complete ACK snapshots.
- 📦 Provision Chrome, Chromium or experimental Lightpanda on demand and reuse cached installations.

Upgrade with `npm install @open-wa/wa-automate@5.5.0`. Install `@open-wa/stickers@5.5.0` directly for the standalone renderer and CLI.

Native methods require their current runtime patches. Private sticker sending deployment remains separate, and calling audio remains a licensed preview. Advanced poll options depend on WhatsApp flags. Scheduled-call cards showed RSVP/calendar controls; phone-share replies failed on the test devices. Lightpanda recovery and full media support remain experimental.
