# @open-wa/runtime-node

Node Effect runtime Layer for open-wa

Part of the [@open-wa v5 monorepo](https://github.com/open-wa/wa-automate-nodejs).

## Development

- `pnpm --filter @open-wa/runtime-node build`
- `pnpm --filter @open-wa/runtime-node test`
- `pnpm --filter @open-wa/runtime-node lint`
- `pnpm --filter @open-wa/runtime-node typecheck`
- `pnpm --filter @open-wa/runtime-node clean`
