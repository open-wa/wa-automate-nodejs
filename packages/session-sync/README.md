# @open-wa/session-sync

Synchronize Open-WA sessions to remote storage (S3/Zstd).

Part of the [@open-wa v5 monorepo](https://github.com/open-wa/wa-automate-nodejs).

## Install

```bash
pnpm add @open-wa/session-sync
```
